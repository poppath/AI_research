## 2. พฤติกรรมผู้บริโภคไทยที่ต้องออกแบบแอดให้สอดคล้อง

### 2.1 "Social commerce + แชท" คือสนามหลัก

- คนไทยซื้อผ่าน **แชท** (Messenger, LINE, WhatsApp) และ **marketplace** มากกว่าหน้าเว็บ brand ตรง ๆ
- **LINE เป็นโครงสร้างพื้นฐาน** (56M+ MAU) → click-to-LINE/WhatsApp มักให้ผลดีกว่า landing page สำหรับ SME ไทย
- **Live selling** เป็นช่องทาง performance จริง: ข้อมูลจาก TikTok (14 ต.ค. 2026) รายงานยอด ~100 ล้านบาท/วัน, ~310,000 ออเดอร์, เฉลี่ย ~322 บาท/ออเดอร์
- **Influencer trust สูงมาก**: งานสำรวจ (Priceza/The Nation, 2025) ระบุ ~83% ของผู้บริโภคไทยเคยซื้อตามคำแนะนำ influencer

**สิ่งที่ต้องทำ**:
- ออกแบบ flow ที่มี **"คุยต่อในแชท"** เป็นทางเลือกหลัก ไม่ใช่ทางเลือกสำรอง
- ใช้ **UGC/creator-style** มากกว่า studio ad
- วัดผลด้วย **qualified conversation** ไม่ใช่แค่ click

### 2.2 Mobile-first + Video-first

- การบริโภคเกือบทั้งหมดเป็นมือถือ → 9:16 คือมาตรฐาน, ตัวอักษรต้องใหญ่พอ, ปุ่มต้องใหญ่
- คนไทยดูวิดีโอแบบ **sound-on** สูงกว่าเฉลี่ยโลกในบางกลุ่ม (โดยเฉพาะ Reels/TikTok) แต่ก็ต้องมี subtitle เสมอ
- ภาษา: **ไทยผสมอังกฤษ** เป็นเรื่องปกติ (เช่น "โปรแรง", "ของมันต้องมี") — แต่ต้องระวังกลุ่มอายุ 45+ ที่อ่านอังกฤษน้อย

### 2.3 ราคาและความโปร่งใส

- **ราคาต้องชัด** ในโฆษณา (คนไทยไม่ชอบ "ทักไปถามราคา" ในสินค้าที่แข่งขันสูง)
- **COD / การเก็บเงินปลายทาง** ยังเป็นปัจจัยตัดสินใจ → ใช้เป็นจุดขายได้
- **รีวิว + ภาพลูกค้าจริง** ทรงพลังกว่า stock photo มาก

### 2.4 กลุ่มเป้าหมายที่ต่างกันมาก

| กลุ่ม | ช่วงอายุ | แพลตฟอร์มหลัก | สิ่งที่ต้องปรับ |
|---|---|---|---|
| Gen Z | 18–27 | IG Reels, TikTok, Threads | ภาษาเร็ว, UGC, ไม่ขายแข็ง |
| Millennials | 28–42 | FB + IG, Reels | หลักฐาน + ราคาคุ้ม |
| Gen X | 43–58 | FB Feed, LINE | ข้อความชัด, เบอร์โทร, ความน่าเชื่อถือ |
| Boomers | 59+ | FB Feed, LINE | ตัวใหญ่, ขั้นตอนน้อย, โทรได้ |

## 3. ปฏิทินการตลาดไทย (ใช้ตั้งแผนงบและครีเอทีฟ)

| ช่วง | เทศกาล/โอกาส | ผลต่อ CPM | ครีเอทีฟที่ควรเตรียม |
|---|---|---|---|
| ม.ค. | ปีใหม่, ตรุษจีน (บางปี) | กลาง | ของขวัญ, เริ่มต้นใหม่ |
| ก.พ. | วาเลนไทน์ | กลาง | คู่รัก, ของขวัญ |
| มี.ค.–เม.ย. | **สงกรานต์** | **สูงมาก** | ท่องเที่ยว, เครื่องดื่ม, ครอบครัว |
| พ.ค. | เปิดเทอม | กลาง–สูง | การศึกษา, อุปกรณ์ |
| มิ.ย.–ก.ค. | Mid-year sale (6.6, 7.7) | กลาง | โปรโมชัน |

## 4. ข้อกำหนดทางกฎหมายและ Compliance

### 4.1 PDPA (พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562)

- การอัปโหลดเบอร์/อีเมลลูกค้าเพื่อทำ Custom Audience/Lookalike = การประมวลผลข้อมูลส่วนบุคคล → ต้องมี **ฐานทางกฎหมาย** (ความยินยอม/สัญญา/ประโยชน์โดยชอบ)
- ข้อมูลที่ส่งให้ Meta ต้อง **hash (SHA-256)** และไม่ส่งข้อมูลอ่อนไหว
- ต้องมี **นโยบายความเป็นส่วนตัว** และช่องทางใช้สิทธิ์เจ้าของข้อมูล
- ระวังการใช้ข้อมูลจาก lead form ต่อเนื่องโดยไม่แจ้งวัตถุประสงค์

### 4.2 กฎเฉพาะอุตสาหกรรม

| อุตสาหกรรม | ข้อกำหนด | ผลต่อโฆษณา |
|---|---|---|
| อาหาร/ยา/เครื่องสำอาง | อย. (Thai FDA) | ห้ามกล่าวอ้างรักษาโรค; ต้องมีเลขสารบบ |
| การเงิน/ลงทุน | SEC / ธปท. | ห้ามการรับประกันผลตอบแทน; ต้องมีคำเตือน |
| สินเชื่อ/สินเชื่อง่าย | ธปท. + Special Ad Category | Meta จำกัดการ targeting |
| อสังหา/จัดหางาน | Special Ad Category | ห้าม targeting ละเอียด |
| สุรา/บุหรี่ | กฎหมายควบคุม | ห้ามโฆษณา/จำกัดอายุขั้นต่ำ |

### 4.3 Special Ad Category ใน Meta

ถ้าธุรกิจเข้าข่าย ที่อยู่อาศัย / การจ้างงาน / สินเชื่อ / ประเด็นสังคม-การเมือง → **ตั้ง category ตั้งแต่สร้างแคมเปญ** (เปลี่ยนภายหลังไม่ได้) และเตรียมรับว่า audience จะแคบลง

## 5. ช่องทางปิดการขายในไทย (เลือกให้ถูก)

| ช่องทาง | เหมาะกับ | ข้อดี | ข้อเสีย |
|---|---|---|---|
| Landing page + PromptPay | แบรนด์ที่มีเว็บ | วัดผลง่าย, scale ได้ | ต้องมีคนดูแลเว็บ |
| Marketplace (Shopee/Lazada/TikTok Shop) | สินค้าทั่วไป | trust สูง, คนซื้ออยู่แล้ว | แข่งราคา, ข้อมูลลูกค้าจำกัด |
| Click-to-LINE | SME/บริการ | คนไทยใช้ทุกวัน | วัดผลยาก, ต้องมีแอดมิน |
| Click-to-Messenger + AI agent | ธุรกิจที่ตอบคำถามบ่อย | automation ได้ | ต้องเทรน knowledge base |
| Click-to-WhatsApp | ลูกค้าต่างจังหวัด/ต่างประเทศ | วัดผลได้ผ่าน CAPI | adoption ต่ำกว่า LINE |
| Live + Meta | แฟชั่น/ของใช้ | conversion สูง | ต้องมีคนขายเก่ง |

**คำแนะนำ**: ใช้ **2 ช่องทาง** — หนึ่งสำหรับ scale (เว็บ/marketplace) หนึ่งสำหรับปิดการขาย/complex product (แชท) แล้ววัดแยกกัน

## 6. ปรับ playbook ให้เข้ากับไทย

| หลักการสากล | ปรับสำหรับไทย |
|---|---|
| Broad targeting | เริ่ม broad + ภาษาไทย, แต่ถ้าสินค้าเฉพาะกลุ่ม (เช่น B2B) ใช้ 3–5 interest กว้างเป็น suggestion |
| CAPI | ถ้าไม่มีเว็บ → ใช้ CAPI ผ่านแพลตฟอร์มแชท/CRM (qualified lead) |
| 9:16 creative | ใส่ subtitle ไทย + ข้อความใหญ่ + ราคาชัด |
| UGC | ใช้ creator ไทยจริงหรือ AI avatar ที่ดูไทยและ disclose |
| Retargeting | ใช้ LINE/Messenger engagement เป็น audience เสริม (ถ้าเชื่อมได้) |
| Lift test | ใช้ geo-split ระหว่างกรุงเทพ/ปริมณฑล/ต่างจังหวัด |
| Pricing | แสดงราคา + COD + การจัดส่ง ให้ครบในโฆษณา |

## 7. Checklist ตลาดไทย

- [ ] เข้าใจว่าลูกค้าปิดการขายที่ไหน (เว็บ/แชท/marketplace) และวัดผลแยกกัน

- [ ] ตั้ง Special Ad Category ถ้าจำเป็น
- [ ] วางแผนงบสำหรับช่วง CPM สูง (สงกรานต์, 11.11, 12.12)

- [ ] ใช้ตัวเลข reach เป็น "กรอบ" ไม่ใช่ "เป้า"
