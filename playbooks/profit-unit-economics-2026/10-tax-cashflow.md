## 2. VAT — จุดที่ธุรกิจส่วนใหญ่เข้าใจผิด

### เกณฑ์

- **รายรับ** (ไม่ใช่กำไร) เกิน **฿1,800,000/ปี** → ต้องจด VAT ภายใน **30 วัน** นับจากวันที่ถึงเกณฑ์
- นับ **รวมทุกช่องทาง** ที่ขายในนามเดียวกัน (Shopee + Lazada + TikTok + LINE + หน้าร้าน)
- นับเป็นรายรับก่อนหักค่าใช้จ่าย

### สิ่งที่ต้องทำเมื่อจด VAT

1. เรียกเก็บ VAT 7% จากลูกค้า (ราคา ฿500 → เก็บ ฿535)
2. ออกใบกำกับภาษี
3. ยื่น ภ.พ.30 ทุกเดือน ภายในวันที่ 15 ของเดือนถัดไป
4. หักภาษีซื้อ (VAT ที่จ่ายตอนซื้อของ/บริการ) ออกได้

### ผลกระทบต่อ CM — ต้องคิดให้ถูก

**ผิด:**
```
CM2 = 535 − 500×...  ← สับสน
```

**ถูก — VAT ไม่ใช่รายได้และไม่ใช่ต้นทุน (ถ้าขอคืนได้):**
```
ราคาขาย (รวม VAT)     535.00
− VAT ขาย 7%          − 35.00
= Net revenue          500.00   ← ใช้เป็นฐานคำนวณทุกอย่าง

COGS (รวม VAT)        107.00
− VAT ซื้อ            −  7.00
= COGS (ไม่รวม VAT)   100.00   ← ใช้เป็นต้นทุน
```

**⚠️ กับดักที่พบบ่อยที่สุด:**
- Commission ที่แพลตฟอร์มหัก = **รวม VAT แล้ว** (เช่น 17.12% = 16% + VAT) → **ห้ามคูณ VAT ซ้ำ**
- Transaction fee 3.21% = 3% + VAT → ก็รวมแล้ว
- แต่ **ถ้าจด VAT แล้ว** VAT ส่วนนี้ **ขอคืนได้** → ต้นทุนจริงคือ 3% ไม่ใช่ 3.21%

**ผลลัพธ์:** ร้านที่จด VAT มี CM2 **ดีขึ้น** 0.21–1.12 pts (เพราะขอคืน VAT จากค่าธรรมเนียมได้)

### ค่าปรับถ้าไม่จด

- เบี้ยปรับ + ดอกเบี้ย **ย้อนหลังได้ถึง 5 ปี**
- ปัจจุบันสรรพากรและแพลตฟอร์ม **แลกเปลี่ยนข้อมูลกัน** — ความเสี่ยงถูกตรวจสอบสูงมาก

## 3. ภ.พ.36 — ภาษีที่คนลืมมากที่สุด

**เมื่อไหร่เกิด:** ซื้อบริการจากต่างประเทศ เช่น
- Facebook / Google / TikTok Ads (ถ้าจ่ายตรงไปต่างประเทศ)
- ค่า SaaS (Shopify, Klaviyo, Canva Pro)
- ค่าบริการ cloud

**วิธีคิด:** ผู้จ่ายต้อง **นำส่ง VAT 7% แทนผู้ให้บริการ** ภายในวันที่ 7 ของเดือนถัดไป

**ตัวอย่าง:**
```
ค่าแอด Facebook ฿100,000/เดือน (จ่ายตรงต่างประเทศ)
ภ.พ.36 ที่ต้องนำส่ง = ฿7,000/เดือน
```

**แต่:** VAT 7% นี้ **ขอคืนเป็นภาษีซื้อได้** (ถ้าจด VAT) → สุทธิเป็นแค่ภาระกระแสเงินสด ไม่ใช่ต้นทุน

**กับดัก:** ร้านที่ยังไม่จด VAT แต่ยิงแอดต่างประเทศตรง → ยังต้องจ่าย ภ.พ.36 และ **ขอคืนไม่ได้** → เป็นต้นทุนจริง 7% ของค่าแอด!

→ ที่ค่าแอด ฿100,000/เดือน = **฿84,000/ปี ที่หายไปเปล่า ๆ**

**ทางเลือก:** ซื้อผ่าน agency ไทย → จ่าย WHT 3% แทน และได้ใบกำกับภาษี

## 4. WHT — ภาษีหัก ณ ที่จ่ายที่ต้องจัดการ

| ประเภทจ่าย | อัตรา WHT |
|---|---|
| ค่าโฆษณาผ่าน agency ไทย | 3% |
| ค่าบริการ (ที่ปรึกษา, ฟรีแลนซ์, agency) | 3% |
| ค่าเช่า | 5% |
| ค่าขนส่ง | 1% |
| ค่า KOL/influencer (บุคคลธรรมดา) | 3% |
| ค่า KOL (นิติบุคคล) | 3% |

**สิ่งที่ต้องทำ:** ออกหนังสือรับรองการหักภาษี ณ ที่จ่าย (50 ทวิ) และนำส่งภายในวันที่ 7 ของเดือนถัดไป

**กับดัก:** ถ้าไม่หัก WHT จาก KOL → **ร้านต้องรับผิดชอบจ่ายเอง** (ภาษีทั้งจำนวน + เบี้ยปรับ)

## 5. กระแสเงินสด: Cash Conversion Cycle

### สูตร

```
CCC = DIO + DSO − DPO

DIO (Days Inventory Outstanding) = สต็อกเฉลี่ย ÷ COGS ต่อวัน
DSO (Days Sales Outstanding)     = ลูกหนี้การค้า ÷ รายได้ต่อวัน (รวม payout delay)
DPO (Days Payable Outstanding)   = เจ้าหนี้ ÷ COGS ต่อวัน
```

### ตัวอย่างร้านไทยทั่วไป

| องค์ประกอบ | ค่า | หมายเหตุ |
|---|---|---|
| DIO (สต็อก) | 45 วัน | สั่งของล่วงหน้า + พรีออเดอร์ |
| DSO (payout จาก marketplace) | 10 วัน | Shopee/Lazada ~7–14 วันหลังส่งสำเร็จ |
| DSO (COD) | 3 วัน | หลังเก็บเงินได้ |
| DPO (จ่ายซัพพลายเออร์) | 20 วัน | ปกติ 30–50% ล่วงหน้า |
| **CCC** | **45 + 10 − 20 = 35 วัน** | |

**ความหมาย:** ทุก ฿1,000,000 ของยอดขายที่โตขึ้น ต้องใช้เงินหมุนเพิ่ม **~฿96,000** (35/365)

### ผลกระทบเมื่อโตเร็ว

| ปี | GMV | เงินหมุนที่ต้องการ | กำไรที่ทำได้ |
|---|---|---|---|
| 2025 | ฿20M | ฿1.9M | ฿600K |
| 2026 | ฿40M | ฿3.8M | ฿1.2M |
| **ส่วนต่าง** | +฿20M | **+฿1.9M** | +฿600K |

→ **โต ฿20M แต่ต้องใช้เงินเพิ่ม ฿1.9M ในขณะที่กำไรได้แค่ ฿600K** = ขาดเงิน ฿1.3M

**นี่คือสาเหตุที่ธุรกิจ profitable ล้มละลาย** — ไม่ใช่เพราะขาดทุน แต่เพราะโตเร็วเกินเงินหมุน

## 6. วิธีลด CCC (เรียงตามผลกระทบ)

| มาตรการ | ผลต่อ CCC | ความยาก |
|---|---|---|
| เจรจา credit term กับซัพพลายเออร์ (30 → 45 วัน) | −15 วัน | กลาง |
| ลด stock holding (สั่งถี่ขึ้น ปริมาณน้อยลง) | −10 วัน | กลาง |
| ใช้ marketplace ที่ payout เร็ว (บางที่มี 3–5 วัน) | −5 วัน | ง่าย |
| เลือกจ่าย COD แทนบัตร (ได้เงินเร็วขึ้น) | −2 วัน | ง่าย |
| เก็บมัดจำ/พรีออเดอร์ก่อนผลิต | −10 ถึง −20 วัน | ยาก (ต้องมีแบรนด์) |
| ใช้ factoring/invoice financing | −10 วัน | ยาก (มีต้นทุน 1–2%/เดือน) |
| **รวมที่เป็นไปได้** | **−30 ถึง −50 วัน** | |

## 7. 5 ตัวเลขการเงินที่ต้องดูทุกเดือน

| # | ตัวเลข | สูตร | เกณฑ์ |
|---|---|---|---|
| 1 | CM3 % | (CM2 − ads) ÷ net revenue | ≥ 22% |
| 2 | CCC | DIO + DSO − DPO | < 45 วัน |
| 3 | Cash runway | เงินสด ÷ (ค่าใช้จ่ายคงที่/เดือน) | > 3 เดือน |
| 4 | Stock turn | COGS ÷ สต็อกเฉลี่ย | > 4 ครั้ง/ปี |
| 5 | กระแสเงินสดจากการดำเนินงาน | กำไร + ค่าเสื่อม − Δworking capital | > 0 ทุกเดือน |

**⚠️ ตัวเลขที่ 5 สำคัญที่สุดและถูกมองข้ามมากที่สุด** — ธุรกิจที่มีกำไรทางบัญชีแต่กระแสเงินสดติดลบจะตายภายใน 6–12 เดือน

## 8. ตารางตัดสินใจ: จด VAT หรือยัง

| สถานการณ์ | ทำอะไร |
|---|---|
| รายรับ < ฿1.2M/ปี | ยังไม่ต้องจด แต่ติดตามรายรับทุกไตรมาส |
| รายรับ ฿1.2M–1.6M/ปี | วางระบบบัญชีให้พร้อมจด — จะถึงเกณฑ์ภายใน 6 เดือน |
| รายรับ ฿1.6M+/ปี | **จดทันที** ก่อนถึงเกณฑ์ |
| รายรับ > ฿1.8M แล้ว | จดภายใน 30 วัน + ปรึกษาผู้ทำบัญชีเรื่องการย้อนหลัง |
| ขาย B2B เป็นหลัก | จดโดยสมัครใจได้ เพราะลูกค้าต้องการใบกำกับภาษี |
| CM2 ต่ำมาก + ยังไม่ถึงเกณฑ์ | อย่าจดโดยสมัครใจ เพราะต้องขึ้นราคา 7% ซึ่งกด CM ต่อ |

**หมายเหตุสำหรับคนที่ยังไม่จด VAT:**
- ค่าแอดต่างประเทศ → ต้องจ่าย ภ.พ.36 เอง และขอคืนไม่ได้ → **เป็นต้นทุนจริง 7%**
- ถ้าค่าแอด > ฿50,000/เดือน การจด VAT โดยสมัครใจ **อาจคุ้มกว่า** เพราะได้ VAT ซื้อคืน

**การคำนวณ:**
```
ถ้าจด VAT โดยสมัครใจ:
+ ได้คืน VAT จากค่าแอด (7% × ad spend)
+ ได้คืน VAT จากค่าธรรมเนียมแพลตฟอร์ม (VAT portion ~0.21–1.12% ของยอด)
− ต้องขึ้นราคา 7% (หรือดูดซับเอง = ลด CM)
− ค่าผู้ทำบัญชีเพิ่ม (~฿3,000–8,000/เดือน)
```

## 9. Anti-pattern ภาษี/เงินสด 7 ข้อ

1. **คิดว่า "ขายในแพลตฟอร์ม แพลตฟอร์มหัก VAT ให้แล้ว"** → ผิด ต้องจด VAT เองถ้าถึงเกณฑ์
2. **คูณ VAT ซ้ำบน commission** → คำนวณ CM ต่ำเกินจริง 0.5–1 pt
3. **ลืม ภ.พ.36** → จ่าย 7% ของค่าแอดเป็นต้นทุนจริงโดยไม่รู้ตัว
4. **ไม่หัก WHT จาก KOL** → ต้องรับผิดชอบเอง + เบี้ยปรับ
5. **ดูแค่กำไร ไม่ดู CCC** → โตเร็วจนเงินขาดมือ
6. **ใช้กำไรทางบัญชีจ่ายเงินปันผล/ขยายสาขา** → เหลือเงินไม่พอจ่าย VAT
7. **สำรองภาษีไม่ครบ** → จ่าย VAT ไม่ทัน → เบี้ยปรับ 1.5%/เดือน

## 10. สรุป 1 หน้า

- VAT 7% เมื่อรายรับรวมทุกช่องทาง > ฿1.8M/ปี — จดภายใน 30 วัน
- VAT ไม่ใช่ทั้งรายได้และต้นทุน (ถ้าขอคืนได้) — ตัดออกทั้งสองข้าง
- Commission/Tx fee ของแพลตฟอร์ม **รวม VAT แล้ว** — ห้ามคูณซ้ำ
- ภ.พ.36 = 7% ของค่าแอดต่างประเทศ ถ้าไม่จด VAT จะขอคืนไม่ได้ = ต้นทุนจริง
- WHT 3% จาก KOL/agency — ถ้าไม่หัก ร้านรับผิดชอบเอง
- CCC 35 วัน = ทุกยอด ฿1M ที่โตขึ้นต้องใช้เงินหมุนเพิ่ม ~฿96K
- ดู **กระแสเงินสดจากการดำเนินงาน** ไม่ใช่แค่กำไร
