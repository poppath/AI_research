# 05 · COD และการตีกลับ — ต้นทุนที่แท้จริง

> **Review 7 พ.ย. 2026:** เอกสารเดิมเป็น research snapshot มีตัวเลข/heuristic และข้ออ้างที่ยังต้องตรวจรายกรณี ไม่ใช่กฎสากลหรือ rate ปัจจุบัน; ก่อนใช้ให้ดู [ข้อจำกัดและรายการแก้ไข](../../REPO-REVIEW-2026-11-07.md) และ `AGENTS.md` โดยเฉพาะก่อนตัดสินใจงบ กฎหมาย หรือ automation.

> as_of: 2026-11 · market: TH · source_type: vendor (NielsenIQ อ้างผ่าน SellerPao, tkdami, KEX, ไปรษณีย์ไทย)

ในตลาดไทย COD ไม่ใช่ "ตัวเลือกการชำระเงิน" แต่เป็น **ประตูเข้าของยอดขาย** — ร้านที่ไม่รับ COD จะเสียยอดจำนวนมาก และร้านที่รับ COD จะต้องแบกต้นทุนที่คนส่วนใหญ่คำนวณต่ำไป 3–5 เท่า

## 2. ต้นทุนจริงของการตีกลับ 1 ครั้ง

**โครงสร้างที่ถูกต้อง (ต้องนับครบ 5 บรรทัด):**

| รายการ | หนึ่งเที่ยวปกติ | เมื่อถูกปฏิเสธ |
|---|---|---|
| ค่าส่งขาไป | ฿35 | ฿35 |
| ค่าส่งขากลับ | — | ฿35 |
| ค่าเก็บเงินปลายทาง (COD fee) | ฿12 | ฿0 (ไม่ได้เก็บ) |
| ต้นทุนสินค้า | ฿180 | ฿180 (มักขายไม่ได้) |
| แพ็ก + จัดการ | ฿8 | ฿14 (ต้อง repack) |
| **รวม** | **฿235** | **฿264** |

`[vendor: tkdami 2026-10-31, ตัวอย่างสินค้าความงามราคากลาง]`

**ข้อที่คนประเมินต่ำที่สุด: ต้นทุนสินค้า**

สินค้าที่เดินทางไป-กลับ:
- ซีลเปิด (กรณีลูกค้าเปิดกล่องตรวจ)
- กล่องบุบ/ครูด
- ผ่านอุณหภูมิที่สูตรไม่ได้รับการทดสอบ (เครื่องสำอาง/สกินแคร์)

→ **ต้องตั้งสมมติฐานเป็น write-off ไม่ใช่ "ของคืนกลับมาขายได้"** — ถ้าขายต่อได้ ให้ใช้ 50% ของต้นทุน ไม่ใช่ 100%

**สำหรับสินค้าที่ขายต่อได้ (เสื้อผ้าที่ยังพับอยู่):**
```
ต้นทุนตีกลับ = 35 (ไป) + 35 (กลับ) + 14 (repack) + 0 (สินค้าขายได้)
             = ฿84 ต่อครั้ง
```

**สำหรับสินค้าที่ขายต่อไม่ได้ (สกินแคร์/อาหาร):**
```
ต้นทุนตีกลับ = 35 + 35 + 14 + 180 = ฿264 ต่อครั้ง
```

**ต่างกัน 3.1 เท่า** — นี่คือเหตุผลที่ refusal rate เดียวกันทำลายธุรกิจหนึ่งแต่ไม่ทำลายอีกธุรกิจ

## 3. ผลกระทบระดับธุรกิจ

**สมมติ:** 1,000 ออเดอร์ COD/เดือน, refusal 12%, สินค้าขายต่อไม่ได้

| รายการ | ค่า |
|---|---|
| ออเดอร์ถูกปฏิเสธ | 120 |
| ต้นทุนต่อครั้ง | ฿264 |
| **ต้นทุนรวม/เดือน** | **฿31,680** |
| เป็น % ของยอด (AOV ฿590 × 1,000) | **5.4%** |

**5.4% ของยอดขาย** — เทียบเท่ากับการขึ้น commission 5.4 pts โดยตรง

ถ้าลด refusal จาก 12% → 8% ได้:
```
ประหยัด = 40 × ฿264 = ฿10,560/เดือน = ฿126,720/ปี
```

**ROI ของมาตรการลด refusal:** ถ้าใช้ระบบยืนยันออเดอร์ราคา ฿3,000/เดือน และลดได้ 4 pts → **ROI 3.5× ภายในเดือนแรก**

## 4. หกมาตรการลด refusal (เรียงตาม ROI)

### มาตรการ 1: Order confirmation ก่อนส่ง ⭐ ROI สูงสุด

ส่ง SMS/LINE ยืนยันก่อนจัดส่ง **เฉพาะออเดอร์ COD มูลค่าสูง** (เช่น > ฿500)

**ข้อความที่ได้ผล:**
```
สวัสดีค่ะ คุณ[ชื่อ] 
ออเดอร์ #[เลข] ยอด ฿[X] (เก็บเงินปลายทาง)
จะจัดส่งวันที่ [วันที่] ถึงประมาณ [ช่วงเวลา]
🙋 ถ้ายังต้องการ กด 1
✋ ถ้ายกเลิก กด 2
(ตอบฟรีก่อน 18:00 วันนี้)
```

**ผลที่คาด:** ลด refusal 3–5 pts ในกลุ่ม high-value
**ต้นทุน:** ค่า SMS ฿0.5–1.5/ข้อความ หรือ LINE push (นับโควตา)

### มาตรการ 2: เพิ่มความเร็วในการส่ง ⭐

Refusal พุ่งสูงเมื่อส่งเกิน 7 วัน (cross-border > 20%)

| ระยะเวลาส่ง | Refusal โดยประมาณ |
|---|---|
| 1–2 วัน | 5%–7% |
| 3–4 วัน | 8%–10% |
| 5–7 วัน | 10%–15% |
| > 7 วัน | 15%–25% |

**การตัดสินใจ:** ถ้าส่งจากต่างประเทศและเกิน 7 วันสม่ำเสมอ → **ย้ายสต็อกเข้าไทย** หรือ **ตั้งราคาให้สะท้อน refusal rate** แล้วทดสอบว่าตลาดยังรับได้

### มาตรการ 3: เลือก creator/influencer จากยอดขายจริง ไม่ใช่ follower

`[vendor: tkdami 2026]` — creator ที่มีประวัติปิดการขายจริงนำมาซึ่งลูกค้าที่ **ตั้งใจซื้อ** มากกว่า ส่วน creator ที่ดังแต่ยอดขายต่ำมักนำมาซึ่ง "impulse order" ที่ refusal สูง

**วิธีวัด:** ดู refund/refusal rate ต่อ creator ไม่ใช่ดูแค่ GMV ที่เขา make ให้

### มาตรการ 4: จำกัด COD สำหรับลูกค้าที่มีประวัติ

- ลูกค้าที่ปฏิเสธครบ 3 ครั้งใน 60 วัน → แพลตฟอร์มตัดสิทธิ์ COD 60 วัน (นโยบาย TikTok Shop)
- **ระดับร้าน:** ตั้งกฎเอง — ลูกค้าที่เคยปฏิเสธ 2 ครั้ง → บังคับ prepay

**ข้อควรระวัง:** ต้องแจ้งให้ชัดตอน checkout ไม่ใช่ปฏิเสธหลังสั่ง

### มาตรการ 5: ระบุสินค้าให้ตรงที่สุด

สาเหตุ refusal อันดับ 2 รองจาก "เปลี่ยนใจ" คือ **"ของไม่ตรงปก"**

- รูปต้องไม่แต่งจนเกินจริง
- ระบุขนาด/น้ำหนัก/สีให้ชัด
- ระบุวันที่ต้องรอ (ถ้าพรีออเดอร์)

### มาตรการ 6: เก็บเงินมัดจำสำหรับออเดอร์สูง

สำหรับออเดอร์ > ฿2,000 — เก็บมัดจำ ฿100–200 ผ่าน PromptPay แล้วเก็บส่วนที่เหลือปลายทาง
**ผล:** refusal ลดลงมาก เพราะลูกค้ามี "skin in the game"
**ต้นทุน:** conversion rate ลดลง 5–15% → **ทดสอบก่อนใช้ทั้งร้าน**

## 5. ข้อกฎหมายที่ต้องรู้: มาตรการ "ส่งดี" (Dee-Delivery)

**สคบ. ออกประกาศ เรื่อง ให้ธุรกิจการให้บริการขนส่งสินค้าโดยเรียกเก็บเงินปลายทาง เป็นธุรกิจที่ควบคุมรายการในหลักฐานการรับเงิน พ.ศ. 2567** — มีผล **3 ต.ค. 2567**

**สาระสำคัญ:**
- ผู้บริโภคมีสิทธิ์ **เปิดกล่องตรวจสินค้าก่อนจ่าย** สำหรับ COD
- ขนส่งต้อง "หน่วงเงิน" ไว้ — ถ้าสินค้ามีปัญหา คืนเงินผู้ซื้อได้เร็ว
- ผู้ซื้อสามารถปฏิเสธรับได้ถ้าสินค้าชำรุด/ไม่ตรงปก/ไม่ได้สั่ง

**ผลกระทบต่อร้าน:**
1. **ค่าใช้จ่ายจากการตีกลับไม่ได้ถูกคุ้มครอง** — กฎหมายคุ้มครองผู้บริโภค ไม่ได้ชดเชยร้าน
2. ร้าน **ไม่สามารถห้ามเปิดกล่อง** ได้
3. ต้องเตรียมรับมือกับ refusal ที่เพิ่มขึ้นในกลุ่มที่ "ลองเปิดดูก่อน"

**สิ่งที่ต้องทำ:**
- ปรับ wording ในหน้า checkout ให้ชัดว่า COD คืออะไร
- ระบุให้ชัดว่าสินค้า "ตรวจสอบภายนอกได้" ไม่ใช่ "ทดลองใช้" (ไปรษณีย์ไทยกำหนดไว้ชัด)
- เตรียม process รับของคืนและ repack

## 6. ทางเลือก: ไม่รับ COD เลยได้ไหม

**คำตอบสั้น: สำหรับหลายหมวด ไม่ได้**

เพราะ:
- ลูกค้าไทยจำนวนมากไม่ซื้อถ้าไม่ใช่ COD (โดยเฉพาะต่างจังหวัด)
- แพลตฟอร์มจัดอันดับสินค้าที่มีตัวเลือก COD สูงกว่า

**ทางเลือกที่เป็นจริง:**

| ทางเลือก | ผลต่อ conversion | ผลต่อ refusal | เหมาะกับ |
|---|---|---|---|
| รับ COD ทุกออเดอร์ | ฐาน | 8–12% | สินค้าราคาต่ำ, ลูกค้าใหม่ |
| COD เฉพาะ < ฿1,000 | −3–8% | −2–4 pts | สินค้า high-ticket |
| COD + มัดจำ ฿100 | −5–15% | −5–8 pts | สินค้า > ฿2,000 |
| ไม่รับ COD | −20–40% | — | สินค้า B2B / ลูกค้าองค์กรเท่านั้น |

**การตัดสินใจ:** ทดสอบเป็น **segmented**: เปิด COD สำหรับลูกค้าใหม่, บังคับ prepay สำหรับลูกค้าที่เคยปฏิเสธ 2 ครั้ง

## 7. วิธีวัด refusal rate ของตัวเอง (สำคัญ)

**นิยามที่ต้องใช้ให้ตรงกัน:**

```
Refusal rate = จำนวนพัสดุที่ถูกปฏิเสธ ÷ จำนวนพัสดุที่ส่งออก
```
❌ ไม่ใช่: จำนวนที่ถูกปฏิเสธ ÷ จำนวนออเดอร์ (เพราะบางออเดอร์อาจส่งซ้ำ)
❌ ไม่ใช่: จำนวนที่ถูกปฏิเสธ ÷ จำนวนที่เก็บเงินได้

**ข้อมูลที่ต้องดึงจากขนส่ง:**
- สถานะ "ตีกลับ" / "Return to sender" / "ผู้รับปฏิเสธ"
- แยกตาม: ขนส่ง, พื้นที่ (กทม./ต่างจังหวัด), ช่วงเวลา, ช่องทางที่ได้ออเดอร์, SKU

**การวิเคราะห์ที่ให้ insight จริง:**

| มิติ | สิ่งที่มักเจอ |
|---|---|
| แยกตามช่องทางที่ได้ลูกค้า | ออเดอร์จาก ads มัก refusal สูงกว่า organic 2–4 pts |
| แยกตาม SKU | SKU ที่รูป misleading มี refusal 20%+ |
| แยกตามพื้นที่ | 3 จังหวัดชายแดน/เกาะ refusal สูงเป็น 2 เท่า |
| แยกตามช่วงเวลา | ออเดอร์ที่สั่ง 22:00–02:00 refusal สูงกว่า |
| แยกตาม creator | ต่างกันได้ 3 เท่า |

**n minimum:** ต้องมีอย่างน้อย 30 ออเดอร์ต่อกลุ่มก่อนสรุป ไม่งั้น noise กลบ signal

## 8. Provision ที่ถูกต้องใน CM

**สูตร:**
```
Provision ต่อออเดอร์ = refusal_rate × ต้นทุนต่อการตีกลับ

โดย ต้นทุนต่อการตีกลับ = ค่าส่งไป + ค่าส่งกลับ + repack + (ต้นทุนสินค้า × % ที่ขายต่อไม่ได้)
```

**ตัวอย่าง 3 หมวด:**

| หมวด | Refusal | ต้นทุน/ครั้ง | Provision/ออเดอร์ |
|---|---|---|---|
| เสื้อผ้า (ขายต่อได้ 80%) | 10% | ฿35+35+14+(180×0.2) = ฿120 | ฿12.00 |
| สกินแคร์ (ขายต่อไม่ได้) | 10% | ฿264 | ฿26.40 |
| เครื่องประดับ (ขายต่อได้ 100%) | 12% | ฿84 | ฿10.08 |

**⚠️ อย่าใช้ค่าเฉลี่ยเดียวทั้งร้าน** — จะทำให้ SKU ที่ refusal สูงดูดีเกินจริง และ SKU ที่ refusal ต่ำถูกกดให้ดูแย่

## 9. สรุป 1 หน้า

- Refusal เฉลี่ย 8–12% แต่ high-ticket 10–20% และ cross-border > 7 วัน > 20%
- ต้นทุนจริง ฿84 (ขายต่อได้) ถึง ฿264 (ขายต่อไม่ได้) — อย่าคิดแค่ค่าส่งกลับ
- ระดับธุรกิจ: 12% refusal = 5.4% ของยอด = เท่ากับ commission +5.4 pts
- มาตรการ ROI สูงสุด: order confirmation (ก่อนส่ง) + เพิ่มความเร็วส่ง + เลือก creator จากยอดขายจริง
- มาตรการ "ส่งดี" บังคับให้ผู้ซื้อเปิดกล่องตรวจได้ → refusal ไม่มีทางลดลงด้วยการห้าม
- **ต้อง provision ใน CM1 และแยกตาม SKU** ไม่ใช่ค่าเฉลี่ยร้าน
