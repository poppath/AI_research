## 2. Weight break: จุดที่ต้นทุนกระโดด

ค่าส่งไทยกระโดดเป็นขั้น ไม่ใช่ต่อเนื่อง:

```
0–1 กก.    ฿23–35     ← 95% ของสินค้าแฟชั่น/ความงามอยู่ในขั้นนี้
1–2 กก.    ฿35–50     ← +50%
2–5 กก.    ฿100–150   ← +200%
5–10 กก.   ฿180–250   ← +400%
```

**นัยเชิงออกแบบสินค้า:**

| ถ้าสินค้าคุณหนัก | ทางเลือก |
|---|---|
| 1.1 กก. (เลยขีด) | ลด packaging 100 กรัม → ประหยัด ฿15–20/ออเดอร์ |
| 2.2 กก. | แยกเป็น 2 พัสดุถ้าขนส่งคิดต่อพัสดุถูกกว่า (คำนวณดูก่อน) |
| 5+ กก. | พิจารณา flat-rate หรือ 3PL ที่รวมค่าส่ง |

**ตัวอย่างจริง:** กล่องเครื่องสำอางที่ใช้กล่องหนา 3 ชั้น → 0.34 กก. เปลี่ยนเป็นถุงบับเบิ้ล + กล่องบาง → 0.21 กก. ยังอยู่ในขั้น ≤1 กก. เท่าเดิม (ไม่ประหยัด) แต่ถ้าเดิม 1.08 กก. → 0.95 กก. **ประหยัด ฿15/ออเดอร์ทันที**

**ROI:** ที่ 1,000 ออเดอร์/เดือน = ฿15,000/เดือน = ฿180,000/ปี จากการเปลี่ยนบรรจุภัณฑ์ครั้งเดียว

## 3. Volumetric weight (น้ำหนักตามปริมาตร)

ขนส่งไทยหลายเจ้าคิดค่าส่งตาม **น้ำหนักที่มากกว่า** ระหว่างน้ำหนักจริงกับน้ำหนักปริมาตร

```
น้ำหนักปริมาตร (กก.) = (กว้าง × ยาว × สูง ซม.) ÷ 6000
```

**ตัวอย่าง:** กล่อง 40×30×20 ซม. = 24,000 ÷ 6000 = **4 กก.** แม้ของจริงหนักแค่ 1.2 กก.

→ ร้านที่ขายของเบาแต่กล่องใหญ่ (หมอน, ของตกแต่ง, กล่องของขวัญ) จ่ายค่าส่งขั้น 2–5 กก. โดยไม่รู้ตัว

**วิธีแก้:**
- ลดขนาดกล่องให้พอดี (ไม่ใช้กล่องใหญ่เผื่อ)
- ใช้ถุง/ซองกรณีทำได้
- ตรวจน้ำหนักปริมาตรในระบบขนส่งทุกครั้ง (ใส่ขนาดในระบบให้ครบ)

**ประหยัดได้:** ฿50–100/ออเดอร์ในสินค้ากลุ่มนี้

## 4. Free-shipping threshold: เครื่องมือที่ทรงพลังที่สุดและใช้ผิดบ่อยที่สุด

### หลักการ

การให้ส่งฟรีคือ **การลดราคาแบบ disguised** ที่:
- ✅ รับรู้คุณค่าได้ง่ายกว่าส่วนลด %
- ✅ กระตุ้นให้เพิ่ม AOV (ถ้าตั้ง threshold ถูก)
- ❌ กิน margin ตรง ๆ เท่ากับค่าส่ง

### สูตรตั้ง threshold ที่ถูกต้อง

```
Threshold ที่เหมาะสม = AOV ปัจจุบัน × 1.25 ถึง 1.40
ต้องผ่านเงื่อนไข: CM2 ที่ AOV ใหม่ − ค่าส่งที่ร้านออก ยัง ≥ CM2 ที่ AOV เดิม
```

**ตัวอย่าง:**

| | ก่อน | หลัง |
|---|---|---|
| AOV | ฿590 | ฿740 (+25%) |
| CM2 % | 28% | 28% |
| CM2 (บาท) | ฿165 | ฿207 |
| ค่าส่งที่ร้านออก | ฿0 | ฿45 |
| **CM2 สุทธิ** | **฿165** | **฿162** |

**ผลลัพธ์:** CM2 ลดลง ฿3 แต่ได้ **ยอดขายเพิ่ม ฿150** ต่อออเดอร์ → ถ้า conversion rate ไม่ตกเลย นี่คือการเติบโตฟรี

**แต่:** ต้องตรวจว่า conversion ไม่ตก และไม่มีลูกค้าเดิม "เพิ่มของที่ไม่ต้องการ" เพื่อให้ถึง threshold (ซึ่งจะเพิ่ม return rate)

### กับดัก 4 ข้อของ free shipping

**กับดัก 1: ตั้ง threshold ต่ำกว่าค่าส่ง × 2**
ถ้าค่าส่ง ฿45 และ threshold ฿600 → CM2 ที่ ฿600 คือ ฿168 − ฿45 = ฿123 ซึ่งอาจต่ำกว่า CM2 ที่ ฿590 แบบไม่ส่งฟรี (฿165)
→ **ต้องคำนวณเสมอ ไม่เดา**

**กับดัก 2: ให้ส่งฟรีทุกออเดอร์**
นี่คือการลดราคา 7.6% (฿45 ÷ ฿590) ทุกออเดอร์ — ถ้า CM2 = 28% คือ **กำไรหาย 27%**
→ ถ้าจะให้ ต้องขึ้นราคาสินค้า 7.6% ก่อน (ซึ่งทำได้ แต่ต้องทำพร้อมกัน ไม่ใช่ทีหลัง)

**กับดัก 3: ไม่แยกตามพื้นที่**
ค่าส่งไป 3 จังหวัดชายแดน/เกาะสูงกว่ากทม. 2–3 เท่า → ถ้าให้ส่งฟรีทุกพื้นที่ จะขาดทุนหนักในบางโซน
→ ทางเลือก: ส่งฟรีเฉพาะพื้นที่ปกติ หรือ เพิ่มขั้นต่ำสำหรับพื้นที่ห่างไกล

**กับดัก 4: ลืมว่า marketplace คิด fee บนยอดรวมค่าส่ง**
บน Shopee/TikTok Shop ถ้าร้าน subsidize ค่าส่ง → transaction fee คิดบนยอดที่ผู้ซื้อจ่าย (ซึ่งรวมค่าส่ง) → ค่าใช้จ่ายจริงสูงกว่าที่คิด 3.21%

## 5. บรรจุภัณฑ์: ต้นทุนที่มองข้าม

| รายการ | ราคา/ชิ้น | หมายเหตุ |
|---|---|---|
| กล่องลูกฟูก 3 ชั้น (20×15×10) | ฿6–12 | ขึ้นกับ volume |
| กล่องลูกฟูก 5 ชั้น | ฿14–22 | สำหรับสินค้าเปราะ |
| ซองบับเบิ้ล | ฿3–6 | |
| ฟิล์มยืด / เทป | ฿1–2 | |
| สติกเกอร์แบรนด์ | ฿0.8–3 | |
| ใบเสร็จ/การ์ดขอบคุณ | ฿1.5–4 | ถ้าพิมพ์เองถูกกว่า |
| **รวมต่อออเดอร์** | **฿12–45** | |

**+ ค่าแรงแพ็ก:** ฿5–12/ออเดอร์ (ถ้าจ้างพนักงาน)

### ต้นทุนบรรจุภัณฑ์ควรอยู่ที่เท่าไหร่

| AOV | บรรจุภัณฑ์ที่สมเหตุสมผล | % ของ AOV |
|---|---|---|
| < ฿300 | ฿8–15 | ≤5% |
| ฿300–800 | ฿12–25 | 3–4% |
| ฿800–2,000 | ฿20–40 | 2–3% |
| > ฿2,000 | ฿35–80 | 1.5–4% (unboxing experience มีค่า) |

**ถ้าสูงกว่า:** ตรวจว่ากำลังใช้กล่องใหญ่เกินจำเป็น หรือใส่ของแถมที่ไม่สร้างยอดซื้อซ้ำ

### บรรจุภัณฑ์ในฐานะเครื่องมือการตลาด (เมื่อไหร่คุ้ม)

- **คุ้ม** ถ้าสร้าง UGC / unboxing content (ธุรกิจความงาม, ของขวัญ, สินค้า premium)
- **ไม่คุ้ม** ถ้าเป็นสินค้าซื้อซ้ำราคาต่ำ ( consumable, ของใช้ประจำวัน) — ลูกค้าไม่ได้สนใจกล่อง

**ตัวชี้วัด:** ถ้าเพิ่มงบบรรจุภัณฑ์ ฿20/ออเดอร์ แล้วได้ UGC เพิ่ม 1 ชิ้นต่อ 50 ออเดอร์ ที่มี reach เฉลี่ย 5,000 views → CPM = ฿200 ซึ่งแพงกว่ายิงแอด — **ไม่คุ้ม** เว้นแต่ content คุณภาพสูงมาก

## 6. 3PL vs in-house: จุดตัด

| ปัจจัย | In-house | 3PL |
|---|---|---|
| ต้นทุนต่อออเดอร์ (ที่ < 50 ออเดอร์/วัน) | ฿18–35 (ค่าแรง+แพ็ก) | ฿35–60 (รวม fulfillment fee) |
| ต้นทุนต่อออเดอร์ (ที่ > 200 ออเดอร์/วัน) | ฿10–18 | ฿22–38 |
| เงินลงทุนเริ่มต้น | ต่ำ | ต่ำ–กลาง |
| ความยืดหยุ่น | สูง | ต่ำ (มี SLA) |
| ควบคุมคุณภาพ | สูง | กลาง |
| จุดตัดทั่วไป | | **~80–150 ออเดอร์/วัน** |

**สำหรับธุรกิจไทยส่วนใหญ่:** ต่ำกว่า 100 ออเดอร์/วัน → in-house ถูกกว่า **ถ้า** คำนวณค่าแรงจริง (ไม่ใช่ "ทำเองไม่คิดเงิน")
สูงกว่า 150 ออเดอร์/วัน หรือมี SKU เยอะ (500+) → 3PL คุ้มกว่าเพราะ error rate ต่ำกว่า และคืนพื้นที่คลัง

**ต้นทุนที่คนลืมใน in-house:**
- ค่าเช่าพื้นที่ ÷ จำนวนออเดอร์
- ค่าแรงแฝงของเจ้าของ (opportunity cost)
- ต้นทุนความผิดพลาด (ส่งผิด/ช้า → refusal + รีวิวลบ)

## 7. ตารางตัดสินใจค่าส่ง + threshold

| สถานการณ์ | ทำอะไร |
|---|---|
| AOV < ฿300, สินค้าเบา | เก็บค่าส่งจริง หรือส่งฟรีเฉพาะขั้นต่ำ ฿350 |
| AOV ฿300–800 | ส่งฟรีขั้นต่ำ AOV × 1.25–1.40, ขึ้นราคา 3–5% ชดเชย |
| AOV > ฿800 | ส่งฟรีทุกออเดอร์ (เพราะ % ต่อ AOV ต่ำ) แต่รวมในราคาแล้ว |
| สินค้าเบาแต่กล่องใหญ่ | ตรวจ volumetric weight ทันที — มักประหยัดได้ ฿50+ |
| refusal > 10% | เลือกขนส่งที่เร็วกว่า (แม้แพงกว่า ฿10) เพราะ refusal ที่ลดลงคุ้มกว่า |
| volume > 100 ชิ้น/วัน | เจรจาราคาขนส่ง — อย่ารับราคาหน้าร้าน |
| หลายช่องทาง | ใช้ขนส่งต่างกันตามช่องทาง ( marketplace มี rate ของตัวเอง) |

## 8. Dashboard: 5 ตัวเลขค่าส่งที่ต้องดูทุกสัปดาห์

1. **ค่าส่งเฉลี่ยต่อออเดอร์** (บาท) — trend ขึ้นหรือลง
2. **ค่าส่ง ÷ AOV (%)** — ควร < 8% (ถ้า > 12% = ปัญหา pricing หรือน้ำหนัก)
3. **% ออเดอร์ที่ร้านออกค่าส่ง** — ถ้า > 60% แสดงว่า threshold ต่ำเกิน
4. **% ออเดอร์ที่น้ำหนักปริมาตร > น้ำหนักจริง** — ถ้า > 20% = ต้องแก้กล่อง
5. **refusal rate แยกตามขนส่ง** — เพื่อเลือกขนส่งที่คุ้มจริง (ไม่ใช่ถูกสุด)

## 9. สรุป 1 หน้า

- ค่าส่งกระโดดเป็นขั้น (1 กก. / 2 กก. / 5 กก.) → การลดน้ำหนัก 100 กรัมอาจประหยัด ฿15–20
- Volumetric weight (÷6000) ทำให้ของเบาแต่กล่องใหญ่จ่ายแพงโดยไม่รู้ตัว
- Free-shipping threshold ที่ดี = AOV × 1.25–1.40 และต้องคำนวณ CM2 ไม่ใช่เดา
- ให้ส่งฟรีทุกออเดอร์ = ลดราคา 7.6% → ต้องขึ้นราคาชดเชยพร้อมกัน
- บรรจุภัณฑ์ ฿12–45/ออเดอร์ — คุ้มเป็นเครื่องมือการตลาดเฉพาะธุรกิจที่ได้ UGC จริง
- จุดตัด 3PL ≈ 80–150 ออเดอร์/วัน
- Volume > 100 ชิ้น/วัน → เจรจาราคา อย่ารับราคาหน้าร้าน
