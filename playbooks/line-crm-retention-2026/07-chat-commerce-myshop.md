# บท 07 · Chat Commerce & MyShop — ปิดการขายในแชท

## TL;DR

- Chat commerce คือจุดแข็งที่แพลตฟอร์มอื่นทำตามไม่ได้ในไทย: ลูกค้าถาม → มีคนตอบ → ปิดการขายในบทสนทนาเดียว
- ตัวเลข "ปิดยอดได้ 85–98%" ที่ถูกอ้างกันเป็นของ **LINE Thailand / agency** และวัดจากคนที่ทักเข้ามาแล้ว — **ไม่ใช่ conversion rate ของทั้ง funnel** `[vendor]`
- สิ่งที่ทำให้ปิดได้: **ตอบเร็ว** (≤ 5 นาที), **ข้อมูลพร้อม** (สต็อก/ราคา/โปร), **ขั้นตอนจ่ายสั้น** (≤ 2 แตะ)
- MyShop ทำให้ LINE กลายเป็นหน้าร้าน: catalog + checkout + point อัตโนมัติ
- **ทุกแชทที่ปิดได้ควรถูก tag** เพื่อป้อนกลับเข้า segmentation — ไม่งั้นคุณเรียนรู้ไม่ได้

---

## 1 · Chat commerce ต่างจาก ecommerce อย่างไร

| มิติ | Ecommerce checkout | Chat commerce |
|---|---|---|
| แรงจูงใจ | มีอยู่แล้ว (intent สูง) | ถูกสร้างระหว่างคุย |
| อัตราปิด | 1–3% ของผู้เข้าชม | สูงกว่ามาก (แต่ denominator ต่างกัน) |
| ปัจจัยชนะ | หน้า checkout, ราคา, รีวิว | **ความเร็วและความชัดของคนตอบ** |
| ต้นทุน | ต่ำต่อออเดอร์ | มีต้นทุนคน |
| Scale | สูง | จำกัดด้วยจำนวนคน/แชท |

**สรุปเชิงกลยุทธ์:** chat commerce เหมาะกับ **AOV สูง (≥ ฿800)**, **สินค้าต้องอธิบาย** (สกินแคร์, supplement, เครื่องใช้), และ **ลูกค้าซื้อซ้ำ**

## 2 · SLA การตอบ — ตัวแปรที่ทรงพลังที่สุด

| เวลาตอบ | ผลโดยประมาณ |
|---|---|
| < 1 นาที | โอกาสปิดสูงสุด |
| 1–5 นาที | ดี |
| 5–30 นาที | ปานกลาง — ลูกค้าอาจไปที่อื่น |
| > 1 ชม. | ต่ำมาก |
| ไม่ตอบ | เสียลูกค้า + block |

**มาตรฐานที่ควรตั้ง**
- เวลาทำการ: ตอบครั้งแรก ≤ 5 นาที
- นอกเวลา: auto-reply ที่บอกเวลา + เก็บข้อมูล (ชื่อ, สินค้าที่สนใจ) แล้วตอบเช้า
- ถ้าเกิน 3 ข้อความยังไม่จบ → escalate ให้หัวหน้า
- วัด **first response time** และ **resolution time** เป็น KPI ของทีม

## 3 · โครงสคริปต์ปิดการขาย (5 ขั้น)

```
1. RECEIVE   ทักกลับภายใน 5 นาที + เรียกชื่อถ้ามี
             "สวัสดีค่ะคุณ [ชื่อ] สนใจ [สินค้า] ใช่ไหมคะ"

2. QUALIFY   ถาม 1–2 คำถามที่จำเป็นจริง (ไม่ใช่แบบสอบถาม)
             "ผิวคุณเป็นแบบไหนคะ มัน/แห้ง/ผสม"

3. RECOMMEND เสนอ 1 ตัวเลือกหลัก + 1 ทางเลือก (ไม่เกิน 2)
             "ตัวนี้เหมาะกับผิวมันค่ะ ใช้แล้ว [ผลลัพธ์] ลูกค้ารีวิว 4.8★"

4. HANDLE    จัดการข้อกังวล: ราคา, ผลข้างเคียง, การจัดส่ง, การรับประกัน
             "ถ้าไม่ถูกใจ คืนได้ภายใน 7 วันค่ะ"

5. CLOSE     ปิดด้วยขั้นตอนเดียว
             ส่งลิงก์ MyShop / สร้างออเดอร์ / ส่ง QR พร้อมเพย์
             "กดลิงก์นี้ได้เลยค่ะ เลือกเก็บเงินปลายทางได้"
```

**ข้อห้าม**
- ❌ ถามคำถาม 5 ข้อก่อนเสนออะไร
- ❌ ส่งแคตตาล็อกทั้งเล่ม
- ❌ ตอบแค่ "มีค่ะ" แล้วรอ
- ❌ ใช้ข้อความสำเร็จรูปซ้ำโดยไม่ปรับตามบริบท
- ❌ หายไปกลางบทสนทนา

## 4 · MyShop — หน้าร้านใน LINE

**ทำอะไรได้**
- แสดงสินค้า + ราคา + สต็อก
- checkout ในแอป LINE
- ผูกกับ MyCustomer CRM → point อัตโนมัติ
- ใช้ร่วมกับ broadcast / rich menu / chat

**ตั้งค่าให้ถูก**
1. ถ่ายภาพสินค้า ≥ 3 ภาพ + วิดีโอสั้น
2. ชื่อสินค้าใส่ keyword ที่คนค้น (ภาษาไทย + อังกฤษ)
3. ราคา + โปรต้องตรงกับทุกช่องทาง (ถ้าไม่ตรง → ลูกค้าโกรธ + claim)
4. ตั้งค่าจัดส่ง + เก็บเงินปลายทาง (COD ยังสำคัญมากในไทย)
5. ผูก point/tier กับ MyCustomer
6. ทดสอบ checkout จริงด้วยตัวเองก่อนเปิด

**ตัวชี้วัด MyShop**
| ตัวชี้วัด | เป้า |
|---|---|
| จำนวนออเดอร์/เดือน | ตามเป้าธุรกิจ |
| AOV | ≥ ค่าเฉลี่ยช่องทางอื่น |
| conversion จาก chat → order | ≥ 15–25% `[est]` |
| ซื้อซ้ำผ่าน MyShop | ≥ 20% ภายใน 90 วัน |

## 5 · LINE SHOPPING vs MyShop

| | LINE SHOPPING | MyShop |
|---|---|---|
| คือ | รวมร้านค้าใน LINE (marketplace-like) | หน้าร้านของคุณเอง |
| ใครเห็น | ผู้ใช้ LINE ที่ค้น/เข้าหน้าร้าน | follower ของคุณ |
| ต้นทุน | แล้วแต่รูปแบบ (มีทั้งฟรี/โปรโมท) | รวมในแพ็กเกจ |
| เหมาะกับ | แบรนด์ที่ต้องการ reach ใหม่ | แบรนด์ที่มีฐาน follower |

**กลยุทธ์:** ใช้ MyShop เป็นหลัก (กำไรดีกว่า) และใช้ LINE SHOPPING เพื่อ exposure

## 6 · COD, การคืนสินค้า และผลต่อ CM

ไทยยังพึ่ง **เก็บเงินปลายทาง** สูง → มีผลตรงกับ unit economics

| ปัญหา | ผลต่อ CM | วิธีลด |
|---|---|---|
| ลูกค้าไม่รับของ (COD refused) | ขาดทุนค่าส่งไป-กลับ | ยืนยันออเดอร์ทางแชทก่อนส่ง |
| คืนสินค้า fashion 20–30% | CM หาย | ตารางไซซ์ละเอียด + รีวิวรูปจริง |
| ที่อยู่ผิด | ส่งซ้ำ | ฟอร์มยืนยัน + ตรวจกับลูกค้า |
| ส่งช้า → รีวิวแย่ | conversion ตกในอนาคต | SLA กับขนส่ง |

**ตัวชี้วัดที่ต้องติดตาม:** return rate, COD refusal rate, delivery time — ทั้งหมดนี้แก้ผ่านแชทได้ก่อนเกิดปัญหา

## 7 · การเชื่อมกับ paid media

```
TikTok/Ads → คลิป → ลิงก์เข้าแชท LINE (พร้อม param)
           → auto-greeting ระบุสินค้าที่สนใจ
           → คนตอบปิดการขาย
           → tag source = src_tt_ads + it_<สินค้า>
           → ป้อนกลับเข้า segmentation
```

**ประโยชน์:** ถ้า paid นำเข้าแชทได้ conversion สูงกว่า landing page มาก → **CPA ที่แท้จริงต่ำกว่าที่รายงาน** และคุณควรย้ายงบบางส่วนมาที่นี่

**ข้อควรระวัง:** ถ้า traffic เยอะจนตอบไม่ทัน → หยุดยิง ads ก่อน ดีกว่าได้ลูกค้าแล้วทิ้ง

## 8 · ทีมและเครื่องมือ

| ขนาด | ทีม | เครื่องมือ |
|---|---|---|
| < 100 แชท/วัน | 1 คน + auto-reply | LINE OA Manager |
| 100–500 แชท/วัน | 2–3 คน + tag standard | OA Chat Package (tag, note, history) |
| > 500 แชท/วัน | ทีม + supervisor + QA | third-party shared inbox + CRM |
| ขาย high-value | + sales closer | CRM + โทรศัพท์ |

**KPI ของทีมแชท**
- first response time
- จำนวนแชท/คน/วัน
- conversion จากแชท → ออเดอร์
- CSAT หรือรีวิวที่พูดถึงการบริการ
- tag completeness (≥ 80%)

---

## กับดักของบทนี้

- ❌ เอา 85–98% ไปใช้เป็นเป้า conversion ของทั้งธุรกิจ
- ❌ ยิง ads เข้า LINE โดยไม่มีคนตอบ
- ❌ ตอบด้วยข้อความสำเร็จรูปที่ไม่ตรงคำถาม
- ❌ ไม่มีระบบ tag → เรียนรู้ไม่ได้
- ❌ ราคาในแชทไม่ตรงกับหน้าเว็บ
- ❌ เปิด MyShop โดยไม่ทดสอบ checkout
