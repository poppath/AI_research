# บท 02 · LINE OA Foundation — ตั้งให้ถูกตั้งแต่ต้น

## TL;DR

- **95% ของปัญหา LINE OA ในไทย ไม่ใช่เรื่อง content แต่เป็นเรื่องโครงสร้าง**: ไม่มี tag standard, ไม่มี source tracking, rich menu ล้าสมัย, ไม่มีเส้นทางคุยกับคนจริง
- เลือกแพ็กเกจด้วยคณิตศาสตร์ ไม่ใช่ความรู้สึก: Free 300 · Basic ฿1,280/15,000 · Pro ฿1,780/35,000 · เกิน 20,000 messages → Pro ถูกกว่าเสมอ (เพราะได้ MyCustomer CRM ฟรี)
- **Reply API ไม่นับโควตา** → chatbot ตอบคำถามซ้ำ ๆ ทำงานได้ฟรีแม้บนแพ็กเกจ Free
- **1 channel = 1 webhook URL** → เลือกแพลตฟอร์มได้แค่เจ้าหลักเจ้าหนึ่ง (อย่าซื้อซ้อน)
- Rich menu คือ homepage ของร้าน — 4 ปุ่มชนะ 6 ปุ่ม เพราะทุกปุ่มที่เพิ่มคือการลดความชัดของปุ่มอื่น
- ถ้าไม่มี **tag standard** ให้ถือว่า CRM ยังไม่เริ่ม

## 1 · ตั้ง OA ให้ถูกใน 5 ขั้น

### ขั้น 1 — Account type และการยืนยัน

| ระดับ | ราคา | ได้อะไร | ควรมีเมื่อ |
|---|---|---|---|
| Unverified | ฟรี | ใช้งานพื้นฐาน | ทดลอง |
| Verified (Blue badge) | ฿888 ครั้งเดียว | ค้นหาเจอ, ความน่าเชื่อถือ, ใช้ add-friend ads ได้ | **ควรมีทันทีที่ทำธุรกิจจริง** |
| Premium (Green shield) | ~฿444–459/ปี + เงื่อนไข | สิทธิ์เพิ่ม, ยืนยันระดับสูง | แบรนด์ใหญ่/บริการการเงิน |

> **Premium ID** (@yourshop) ~฿444/ปี — เปลี่ยนไม่ได้ภายใน 1 ปี → เลือกให้ดีตั้งแต่แรก

### ขั้น 2 — เลือกแพ็กเกจด้วยคณิตศาสตร์

```
messages ที่ใช้ต่อเดือน = จำนวนเพื่อน × จำนวนครั้งที่ส่งถึงทุกคน + targeted sends
```

| สถานการณ์ | เพื่อน | ส่ง/เดือน | messages | แพ็กเกจ | ค่าใช้จ่าย |
|---|---|---|---|---|---|
| ร้านเล็ก | 250 | 1 all | 250 | Free | ฿0 |
| ร้านเสริมสวย | 1,500 | 2 all | 3,000 | Basic | ฿1,280 |
| คลินิก | 4,000 | 1 all + 2 targeted (1,000) | 6,000 | Basic | ฿1,280 |
| รถยนต์ | 6,000 | 2 all + 1 targeted (2,000) | 14,000 | Basic | ฿1,280 |
| Online shop | 8,000 | 3 all | 24,000 | Pro | ฿1,780 |
| Retail chain | 20,000 | 2 all | 40,000 | Pro + 5,000 เกิน | ฿1,780 + ฿300 = ฿2,080 |

**จุดตัดที่ต้องจำ:**
- เกิน **20,000 messages** → Pro ถูกกว่า Basic+overage
- ถ้าจะซื้อ MyCustomer CRM (฿369) อยู่แล้ว → **Pro คุ้มตั้งแต่ ~16,310 messages**
- **โควตารีเซ็ตทุกเดือน ไม่ทบไปเดือนหน้า** → อย่าเผื่อ quota ไว้

> ⚠️ ตัวเลขแพ็กเกจ ณ ต.ค. 2026 (ไม่รวม VAT 7%) — LINE ปรับราคาหลายครั้งแล้ว ต้องเช็คหน้า LINE for Business ไทยก่อนตั้งงบ

### ขั้น 3 — Greeting message
ส่งครั้งเดียวตอน add friend — **ต้องบอกว่า "บัญชีนี้มีไว้ทำอะไร" และขอข้อมูล 1 อย่าง** ไม่ใช่แบบสอบถาม 5 ข้อ

**โครงที่ใช้ได้ (≤3 bubble):**
```
bubble 1  ทักทาย + คุณค่าที่จะได้รับใน 1 บรรทัด
bubble 2  quick reply 2–3 ปุ่มถามความสนใจ (skin concern / ประเภทสินค้า / สาขา)
bubble 3  ของขวัญต้อนรับ: code / point / สิทธิ์ — ต้องใช้ได้จริงและไม่ทำ margin พัง
```

### ขั้น 4 — Rich menu
ทำหน้าที่เป็น **homepage** — 4–6 ปุ่มตาม intent ไม่ใช่ตามแผนก

| ประเภทธุรกิจ | ปุ่มที่ควรมี |
|---|---|
| Retail | สินค้า · โปรโมชัน · แต้ม/สมาชิก · สาขา |
| F&B | เมนู · สั่งอาหาร · คูปอง · สาขา |
| Beauty / Clinic | จองคิว · ปรึกษา · รีวิว · ติดตามคำสั่งซื้อ |
| Service | ขอใบเสนอราคา · แผนที่ · แชทเจ้าหน้าที่ · FAQ |

**หลักที่ต้องยึด**
- 1 หน้าจอ ≤ 6 ปุ่ม, แนะนำ 4
- ปุ่มที่กดแล้วต้องไปถึงใน ≤ 2 แตะ
- ใช้ **per-user rich menu** (dynamic) แยกใหม่ / active / lapsed ถ้าทำได้
- เปลี่ยน menu ตามแคมเปญ แต่ต้องมี owner และวันหมดอายุ
- **ทุกปุ่มต้องวัดได้** — กดได้เท่าไร และเกิด conversion ต่อไหม

### ขั้น 5 — เส้นทางคุยกับคนจริง
Automation ปิดประตูการขายได้ ถ้าไม่มี "คุยกับเจ้าหน้าที่" ทางออกที่ชัดเจน
- ปุ่ม/คำสั่งที่เรียกคนได้ทุกเมื่อ
- ตารางคนรับผิดชอบ (ใครรับช่วงไหน)
- เป้าเวลาตอบ: business hours ≤ 1 ชม. · นอกเวลา ตอบครั้งแรกอัตโนมัติแล้วตั้ง SLA
- ถ้าเกิน 3 ข้อความแล้วยังไม่จบ → escalate

## 2 · Message types และเมื่อไรควรใช้อะไร

| รูปแบบ | ข้อดี | ข้อจำกัด | ใช้เมื่อ |
|---|---|---|---|
| Text | เบา, quota เท่าเดิม | ไม่มีภาพ | แจ้งเตือนสั้น |
| **Bubble สูงสุด 3 ต่อ 1 send** | ยืดหยุ่น, ใส่ปุ่มได้ | นับเป็น 1 message | เกือบทุกกรณี |
| Image / Video | ดึงดูด | หนัก, ต้องตั้งใจดู | launch, demo |
| **Carousel** | โชว์หลาย SKU | คนดูแค่ 2–3 ใบแรก | โปรหลายรายการ |
| Coupon | วัดผลได้ | ต้องแลกจริง | acquisition / win-back |
| Reward Card | ทำงานได้บนแพ็กเกจ Free | ไม่เก็บข้อมูล | ร้านเล็ก |
| Quick Reply | ลดการพิมพ์ | จำกัดจำนวน | greeting, ถามความสนใจ |

## 3 · Chat Tags — หัวใจที่คนมองข้าม

**ปัญหา:** ทีมตอบแชทใช้ tag ไม่เหมือนกัน → ข้อมูลใช้ไม่ได้ → broadcast เจาะกลุ่มไม่ได้

**แก้ด้วย Tag Standard 3 มิติ**

```
มิติที่ 1 — SOURCE (มาจากไหน)
  src_qr_store / src_qr_receipt / src_tt_ads / src_web / src_creator / src_chat

มิติที่ 2 — STAGE (อยู่ขั้นไหน)
  st_new / st_browsed / st_carted / st_bought_1 / st_bought_2plus / st_lapsed_60 / st_lapsed_120

มิติที่ 3 — VALUE / INTENT (สนใจอะไร)
  it_<category>  เช่น it_serum / it_sunscreen
  vl_high (AOV ≥ 2× ค่าเฉลี่ย) / vl_low
```

**กฎการใช้งาน**
1. tag ต้องมี**รายการปิด** (closed list) ห้ามพิมพ์เอง — ไม่งั้นจะได้ 40 แบบที่หมายถึงอย่างเดียวกัน
2. ตั้ง **auto-tag** จาก rich menu / keyword / link ที่คลิก
3. tag ที่ไม่ถูกใช้ 90 วัน → ลบ
4. ห้ามใส่ข้อมูลอ่อนไหวใน tag (โรค, ยา, ศาสนา) — ผิด PDPA (ดูบท 10)
5. Manual tag ≤ 300 แท็กต่อแชท (ตามข้อจำกัดของ OA Chat Package)

## 4 · โครงสร้างบัญชีที่แนะนำ (สำหรับหลายแบรนด์/หลายสาขา)

```
Brand A
├── OA หลัก (prospecting + service + broadcast)
├── OA สาขา (เฉพาะกรณีมีหน้าร้านหลายจังหวัด — จำเป็นเมื่อโปรต่างกัน)
└── OA VIP / Membership (ถ้าต้องการประสบการณ์แยก)

Brand B
└── OA แยกโดยสิ้นเชิง (ห้ามรวมแบรนด์ใน OA เดียว)
```

**เหตุผล:** broadcast ที่พูดถึงหลายแบรนด์พร้อมกันทำให้ CTR ตกและ block rate สูงขึ้น

## 5 · Checklist ก่อนเปิดใช้งานจริง

- [ ] verified account (blue badge)
- [ ] Premium ID ที่จำง่าย
- [ ] แพ็กเกจตรงกับ message volume ที่คำนวณแล้ว
- [ ] greeting message + quick reply
- [ ] rich menu 4 ปุ่ม + ภาพถูก spec
- [ ] tag standard 3 มิติ ประกาศให้ทีมใช้เหมือนกัน
- [ ] auto-reply FAQ ครบ 10 คำถามที่ถูกถามบ่อยสุด
- [ ] เส้นทาง "คุยกับเจ้าหน้าที่" + SLA
- [ ] privacy notice + consent capture (บท 10)
- [ ] ผูก LINE Login / MyShop / POS ถ้ามี
- [ ] UTM / source tracking ทุกจุดแจก QR
- [ ] dashboard 12 ตัวเลข (METRICS.md)
- [ ] ตั้ง owner + วันรีวิวรายเดือน

## กับดักของบทนี้

- ❌ ใช้ rich menu 6–9 ปุ่มเพราะ "มีที่ว่าง" → ทุกปุ่มแย่งกัน
- ❌ ตั้ง auto-reply 20 แบบจนลูกค้าไม่เจอคน
- ❌ tag ด้วยมือโดยไม่มีมาตรฐาน → ข้อมูลใช้ไม่ได้ใน 3 เดือน
- ❌ เลือก Free plan ทั้งที่มีเพื่อน 3,000 คน แล้วส่งไม่ได้เมื่อถึงโควตา
- ❌ ซื้อ third-party chatbot 2 เจ้า → webhook ชนกัน
- ❌ ปล่อย rich menu ที่โปรหมดอายุแล้ว → ลูกค้าผิดหวัง
