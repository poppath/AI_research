# บท 06 · Broadcast Playbook — ส่งให้ถูกคน ถูกเวลา

## TL;DR

- Broadcast คือเครื่องมือที่มีกำลังที่สุดและทำลายแบรนด์ได้เร็วที่สุดใน LINE — เพราะมันกินทั้ง quota และ block rate
- **ค่าตั้งต้น 2–4 ครั้ง/เดือน** ไม่ใช่ทุกสัปดาห์; เพิ่มได้เฉพาะเมื่อ block rate ต่ำและ segment แคบ
- ทุก broadcast ควรมี **เป้าหมายเดียว + CTA เดียว** — ถ้าต้องพูด 3 เรื่อง ให้แยก 3 ครั้ง
- **เวลาไทยที่ได้ผล:** 07:00–09:00, 12:00–13:00, 18:00–20:00, 21:00–23:00 — แต่ทดสอบกับฐานของคุณเองเสมอ
- ตัวเลขที่ต้องเฝ้า: open rate, CTR, **block rate**, และ revenue per message
- **Value-first ratio 70/20/10**: 70% มีประโยชน์, 20% โปรโมท, 10% ขายตรง

---

## 1 · Broadcast vs Targeted vs Step Message

| เครื่องมือ | ต้นทุน | ใช้เมื่อ |
|---|---|---|
| **Broadcast (all friends)** | 1 message × จำนวนเพื่อน | เฉพาะเรื่องที่ทุกคนต้องรู้ (ปิดปรับปรุง, อีเวนต์ใหญ่) |
| **Targeted broadcast (segment)** | 1 × จำนวนในกลุ่ม | กรณีปกติ ← ใช้เป็นหลัก |
| **Step message (scenario)** | 1 × ผู้รับ | automation trigger |
| **Timeline post** | ฟรี | เนื้อหาเบา ๆ ไม่ต้องถึงทุกคน |
| **Chat (1:1)** | ฟรี (ถ้าเป็นการตอบ) | บริการ + ปิดการขาย |

**กฎ:** ถ้า broadcast ถึง 100% ของฐานมากกว่า 1 ครั้ง/เดือน ถือว่าส่งถี่เกิน

---

## 2 · Quota math ก่อนส่งทุกครั้ง

```
messages ที่ใช้ = จำนวนผู้รับ (หลังหักคน block)
remaining quota = โควตาแพ็กเกจ − ที่ใช้ไปแล้ว
ต้นทุนจริงต่อ send = (ค่าข้อมูลส่วนเกิน × messages) หรือ 0 ถ้ายังอยู่ในโควตา
```

**ตัวอย่าง:** Pro ฿1,780 / 35,000 messages
- ส่งถึง 8,000 คน → 8,000 messages → ทำได้ 4 ครั้ง/เดือนในโควตา
- ถ้าส่ง 5 ครั้ง → 40,000 → เกิน 5,000 × ฿0.06 = ฿300 เพิ่ม

**ทางเลือกที่ถูกกว่า:** target ให้แคบลง (เช่น ส่งถึง 2,500 คนที่มีโอกาสจริง) แทนส่ง 8,000 คน

## 3 · โครงสร้างข้อความที่ทำงาน (3 bubble)

```
bubble 1 — HOOK
  ประโยคเดียว ≤ 12 คำ, บอกว่าทำไมต้องอ่านตอนนี้
  + ภาพ/วิดีโอสั้น

bubble 2 — VALUE / PROOF
  สิ่งที่ได้รับ + เหตุผล (ราคา, ของแถม, ผลลัพธ์)
  หลักฐาน 1 ชิ้น (รีวิว/ตัวเลข/ภาพก่อน-หลังที่ถูกต้องตามกฎหมาย)

bubble 3 — CTA
  ปุ่มเดียว ชัดเจน ("ซื้อเลย" / "ดูโปร" / "จองคิว")
  optional: วันหมดอายุ
```

**ข้อห้าม**
- ❌ 3 bubble ที่พูด 3 เรื่อง
- ❌ ข้อความยาวเกิน 500 ตัวอักษรใน bubble หลัก
- ❌ หลายปุ่มในข้อความเดียว (ยกเว้น quick reply ≤3)
- ❌ ขึ้นต้นด้วย "สวัสดีค่ะ/ครับ" ทุกครั้ง (เปลืองพื้นที่)

## 4 · ปฏิทิน broadcast ตัวอย่าง (8 สัปดาห์)

| สัปดาห์ | กลุ่ม | เนื้อหา | เป้า |
|---|---|---|---|
| 1 | Champions + Loyal | early access สินค้าใหม่ | AOV |
| 2 | New + Recent | เนื้อหาให้ความรู้ (ไม่ขาย) | engagement |
| 3 | ทั้งฐาน (ครั้งเดียว/เดือน) | โปรหลักของเดือน | revenue |
| 4 | At Risk | win-back เบา | retention |
| 5 | Loyal + Potential | cross-sell / bundle | AOV |
| 6 | New | 2nd-purchase offer | conversion |
| 7 | Champions | ของขวัญ/สิทธิพิเศษ (ไม่ต้องซื้อ) | loyalty |
| 8 | ทั้งฐาน | เตือน event/ปิดรอบ | revenue |

> หมายเหตุ: "ทั้งฐาน" 2 ครั้งใน 8 สัปดาห์ = 1 ครั้ง/เดือน ตามที่แนะนำ

## 5 · เวลาและความถี่ (ไทย)

**ช่วงเวลาที่มี engagement สูง**
| ช่วง | พฤติกรรม |
|---|---|
| 07:00–09:00 | ระหว่างเดินทาง / ก่อนเริ่มงาน |
| 12:00–13:00 | พักเที่ยง |
| 18:00–20:00 | เดินทางกลับ / ก่อนอาหารเย็น |
| 21:00–23:00 | ก่อนนอน ← peak ของการช้อป |

**ทดสอบแบบถูกวิธี**
- 1 ตัวแปรต่อครั้ง (เวลา / ข้อความ / ข้อเสนอ)
- กลุ่มทดสอบ ≥ 1,000 คน ต่อ variation
- รอ 24 ชม. ก่อนสรุป
- ถ้าต่างกัน < 10% ถือว่าไม่ต่าง

**วันในสัปดาห์**
- อัตราเปิดสูง: อังคาร–พฤหัส
- อัตราซื้อสูง: พฤหัส–อาทิตย์ (รวมเงินเดือนต้นเดือน/ปลายเดือน)
- วันเงินเดือนออก (25–1) → โปรแรงได้ผลกว่า

## 6 · เนื้อหาตามเป้าหมาย

| เป้าหมาย | โครงข้อความ | ตัวอย่าง |
|---|---|---|
| ขายตรง | hook ราคา + proof + CTA | "เหลือ ฿390 จาก ฿590 วันนี้ถึงเที่ยงคืน" |
| AOV | bundle / ขั้นบันไดส่งฟรี | "ซื้อครบ ฿1,200 ส่งฟรี + ของแถม" |
| Retention | สิทธิ์ / point / ขอบคุณ | "point 300 คะแนนของคุณจะหมดอายุ 30 พ.ย." |
| Reactivation | เตือนคุณค่า ไม่ใช่ส่วนลดก่อน | "มีสินค้าใหม่ที่ตรงกับที่คุณเคยซื้อ" |
| Education | 3 เคล็ดลับ + soft CTA | "3 วิธีใช้เซรั่มให้เห็นผลใน 14 วัน" |
| Event | วันเวลา + สิ่งที่ได้ | "Live สดคืนนี้ 20:00 ลดพิเศษเฉพาะในไลฟ์" |

## 7 · คุม block rate — ตัวชี้วัดที่สำคัญที่สุด

**สาเหตุที่คน block**
1. ส่งถี่เกิน
2. เนื้อหาไม่เกี่ยวกับเขา
3. ส่งผิดเวลา (ตี 2)
4. ข้อความยาว ไม่มี CTA
5. สัญญาแล้วไม่ทำ (บอกว่าจะมีของแถม แล้วเงียบ)

**มาตรการ**
| มาตรการ | ผล |
|---|---|
| cap ต่อ segment | ลด block 30–50% `[est]` |
| ยกเลิกส่งถึง Lost | ลดต้นทุน + ลด block |
| 1 ข้อความ = 1 เรื่อง | เพิ่ม CTR |
| ใส่ "ไม่ต้องการรับข่าวสาร" ทุกครั้ง | ลด block (เพราะเขาเลือกวิธีอื่น) |
| ตรวจ block rate รายสัปดาห์ | เห็นปัญหาก่อนสาย |

**เกณฑ์แจ้งเตือน**
| Block rate (30 วัน) | การกระทำ |
|---|---|
| < 3% | ปกติ |
| 3–5% | เฝ้าดู, ทบทวนความถี่ |
| 5–8% | ลดความถี่ลง 50% + ตรวจคุณภาพการแบ่งกลุ่ม |
| > 8% | หยุด broadcast 2 สัปดาห์, ส่งเฉพาะ 1:1 |

## 8 · วัดผล broadcast

**ตัวชี้วัดต่อ 1 ครั้ง**
```
open rate      = เปิด / ส่งถึง
CTR            = คลิก / เปิด
conversion     = ซื้อ / คลิก
revenue        = ยอดขายจาก campaign (ใช้ UTM/Code)
RPM            = revenue ÷ messages ที่ใช้     ← ตัวเลขที่ควรใช้เปรียบเทียบ
```

**RPM เป็นตัวตัดสิน:** ถ้า RPM ของ broadcast ต่ำกว่าต้นทุนต่อ message มาก แปลว่าข้อความนั้นควรถูกยกเลิก หรือกลุ่มนั้นไม่ควรถูกส่ง

**ตัวชี้วัดรายเดือน**
- จำนวน send / เพื่อน
- block rate
- revenue จาก broadcast vs flow vs chat
- จำนวนเพื่อนใหม่ vs เพื่อนที่หาย (net growth)

## 9 · Broadcast ที่ดี vs แย่ (ตัวอย่างจริง)

**แย่**
```
สวัสดีค่ะลูกค้า ขอแจ้งโปรโมชั่นพิเศษ!!
สินค้าลดราคาหลายรายการ ตั้งแต่ 10%-50%
มีทั้งครีม เซรั่ม อาหารเสริม และของใช้
สนใจสอบถามได้เลยนะคะ 🙏
```
ปัญหา: ไม่มีเป้าหมาย, ไม่มี CTA, พูด 3 เรื่อง, ไม่มีเหตุผลว่าทำไมต้องตอนนี้

**ดี**
```
bubble 1  เซรั่มที่คุณซื้อเดือนที่แล้ว เหลือ 12 ขวด
bubble 2  ลูกค้า 8 ใน 10 ซื้อซ้ำภายใน 45 วัน (รีวิว 4.8★)
bubble 3  [ซื้อซ้ำ ฿690 จาก ฿890]  ถึง 30 พ.ย.
```
ทำไมดี: เจาะคนที่ซื้อจริง, มี scarcity จริง, มี proof, CTA เดียว, มี deadline

## กับดักของบทนี้

- ❌ Broadcast ทุกสัปดาห์ถึงทั้งฐาน
- ❌ ใช้ broadcast แทน customer service
- ❌ ส่งโปรโดยไม่ตรวจว่าสต็อกพอ
- ❌ ส่งตอนตี 1–5 (LINE อนุญาต แต่คน block)
- ❌ ไม่มี UTM/code → วัดไม่ได้ว่ามาจากไหน
- ❌ ข้อความเดียว 3 เรื่อง 3 ปุ่ม
- ❌ ใช้ "สวัสดีค่ะ" + emoji 5 ตัวเปิดเรื่องทุกครั้ง
