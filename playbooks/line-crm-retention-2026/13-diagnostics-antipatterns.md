# บท 13 · Diagnostics & Anti-patterns — แก้ปัญหาให้ถูกจุด

## TL;DR

- เมื่อ "ยอดไม่โต" คนมักเริ่มแก้ที่ content — แต่ลำดับที่ถูกคือ **tracking → segment → flow → ข้อความ → offer → acquisition**
- **block rate คือ vital sign** — ถ้าสูงขึ้นทุกอย่างที่เหลือจะพังตาม ไม่ว่าจะเขียนข้อความดีแค่ไหน
- 3 อาการที่พบบ่อยที่สุด: เพื่อนเยอะแต่ไม่ซื้อ · ซื้อครั้งเดียวไม่กลับ · ยอดตกโดยไม่รู้สาเหตุ
- ทุกการแก้ต้องมี **baseline + ระยะทดสอบ + เกณฑ์ตัดสิน** ไม่งั้นจะวนแก้ไม่จบ
- 20 anti-patterns ท้ายบทคือ checklist ที่ควรอ่านก่อนวางแผนทุกครั้ง

---

## 1 · Diagnostic Ladder (ไล่ตามลำดับ ห้ามข้าม)

```
ขั้น 1  TRACKING     — เราวัดถูกไหม? (tag ครบ, UTM, source)
ขั้น 2  SEGMENT      — เราส่งถึงคนที่ควรได้รับไหม?
ขั้น 3  FLOW         — มีระบบดูแลหลังบ้านไหม?
ขั้น 4  MESSAGE      — ข้อความ/media ทำงานไหม?
ขั้น 5  OFFER        — ข้อเสนอคุ้มไหม?
ขั้น 6  ACQUISITION  — ต้องหาคนเพิ่มไหม?
```

**กฎ:** ถ้าขั้น 1 ไม่ผ่าน ห้ามไปขั้น 2 — ตัวเลขที่ได้จะหลอกคุณ

## 2 · อาการ → สาเหตุ → การแก้

### 2.1 เพื่อนเยอะ แต่ยอดขายไม่ขึ้น

| สาเหตุที่เป็นไปได้ | วิธีตรวจ | การแก้ |
|---|---|---|
| ได้เพื่อนจากของแถม | ดู first purchase rate 30 วัน | เปลี่ยน incentive เป็นสิทธิ์ซื้อ |
| ไม่มี welcome flow | ตรวจว่า greeting มีกี่ bubble | สร้าง F1 ทันที |
| ข้อความแรกขายเลย | ดู block rate 7 วันแรก | เปลี่ยนเป็นคุณค่า/การศึกษา |
| rich menu ไม่มีทางไปซื้อ | กดเองดู | เปลี่ยนปุ่มให้เป็น CTA |
| ไม่มีคนตอบแชท | ดู first response time | เพิ่มคน / ตั้ง SLA |

### 2.2 ซื้อครั้งเดียวแล้วไม่กลับ

| สาเหตุ | วิธีตรวจ | การแก้ |
|---|---|---|
| CM₁ บาง → ไม่มีงบทำ retention | คำนวณ unit economics | แก้ราคา/ต้นทุนก่อน |
| ไม่มี 2nd purchase flow | ตรวจ flow inventory | สร้าง F2 |
| trigger 2nd purchase ผิดเวลา | เทียบรอบใช้สินค้าจริง | ปรับ trigger |
| สินค้าไม่ตรงความคาดหวัง | อ่านรีวิว 1–2 ดาว | แก้ product/communication |
| ส่งของช้า/แพ็คเสียหาย | delivery time + complaint rate | แก้ ops |

### 2.3 Block rate พุ่ง

| สาเหตุ | วิธีตรวจ | การแก้ |
|---|---|---|
| ส่งถี่เกิน | messages/เดือน | ลด 50% ทันที |
| ส่งทั้งฐานทุกครั้ง | สัดส่วน targeted | เปลี่ยนเป็น segment |
| เนื้อหาไม่เกี่ยวกับเขา | CTR ราย segment | ปรับ group |
| ส่งผิดเวลา | เวลาส่ง | เลื่อนเข้า peak |
| ไม่มี opt-out ที่ชัด | ตรวจข้อความ | ใส่ทุกครั้ง |

### 2.4 Flow ทำงานแต่ conversion ต่ำ

| สาเหตุ | วิธีตรวจ | การแก้ |
|---|---|---|
| ข้อความยาว ไม่มี CTA เดียว | อ่านเอง | โครง 3 bubble |
| offer อ่อน | เทียบราคาตลาด | ปรับของแถม/ส่งฟรี |
| ส่งผิด segment | cohort ของผู้รับ | เพิ่ม condition |
| ไม่มี social proof | ดูข้อความ | เพิ่มรีวิว/ตัวเลข |
| หน้าปลายทางช้า/พัง | ทดสอบเอง | แก้ LP/MyShop |

### 2.5 ยอด LINE ตกกะทันหัน

```
□ มีอะไรเปลี่ยนในระบบ? (flow, menu, ข้อความ)
□ มีของหมด / ราคาเปลี่ยน / โปรหมดอายุ?
□ มีการ block ผิดปกติ?
□ ข้อความล่าสุดถูก reject หรือไม่ (ส่งไม่ถึง)
□ เปลี่ยนแพ็กเกจ/quota หมดกลางเดือน?
□ คู่แข่งมีโปรใหญ่?
□ มีข่าวลบ / รีวิวแย่?
```

## 3 · Recovery Playbook เมื่อ block rate > 8%

```
ชั่วโมง 0    หยุด broadcast ทั้งหมด (ยกเว้น transactional)
24 ชม.      ส่งข้อความขอโทษ/ปรับปรุง (1 ครั้ง, ทั้งฐาน) + เสนอ opt-out
สัปดาห์ 1   ส่งเฉพาะ 1:1 ที่จำเป็น, ฟื้นความน่าเชื่อถือด้วยเนื้อหา
สัปดาห์ 2   เริ่ม targeted broadcast กับ Champions/Loyal เท่านั้น
สัปดาห์ 3–4 ขยาย segment ทีละกลุ่ม, วัด block rate ทุกครั้ง
หลัง 30 วัน ถ้า block ยัง > 5% → ลดความถี่ถาวร 50%
```

## 4 · 20 Anti-patterns

```
1   วัดจำนวนเพื่อนแทน repeat rate
2   broadcast ทั้งฐานทุกสัปดาห์
3   ไม่มี tag standard
4   ไม่มี exit condition ใน flow
5   welcome flow มีแต่การขาย
6   ใช้ส่วนลดเป็นข้อความแรกเสมอ
7   ไม่มี 2nd purchase flow
8   trigger replenishment ด้วยค่าเฉลี่ยทั้งฐาน
9   ไม่มี cap ความถี่
10  ส่งข้อมูลสุขภาพ/ศาสนาเข้า segment
11  pre-tick consent
12  ไม่มี opt-out ในข้อความ
13  ตอบแชทช้าเกิน 1 ชม.
14  ใช้ 2 chatbot platform พร้อมกัน
15  rich menu ล้าสมัย/โปรหมดอายุ
16  วัดด้วย open rate อย่างเดียว
17  ใช้ blended LTV ตัดสินงบ
18  ยิง ads เข้า LINE โดยไม่มีคนตอบ
19  ไม่มี change log
20  ไม่เคยทดสอบ A/B
```

## 5 · ก่อนสรุปว่า "LINE ไม่ work" ให้ตอบ 7 คำถามนี้

1. tag ครบ ≥ 80% ไหม?
2. มี welcome + 2nd purchase flow หรือยัง?
3. block rate เท่าไร?
4. first response time เท่าไร?
5. มีคนตอบแชทช่วง 18:00–23:00 ไหม?
6. วัด revenue จาก LINE แยก flow/broadcast/chat ได้ไหม?
7. CM₁ บวกหรือลบ?

**ถ้าตอบ "ไม่"/"ไม่มี" ข้อใดข้อหนึ่ง → ปัญหาไม่ใช่ LINE**

---

## 6 · การทดสอบที่ถูกต้อง

**โครง A/B บน LINE**
```
1. สุ่ม 50/50 จาก segment เดียวกัน (≥ 1,000 คนต่อกลุ่ม)
2. เปลี่ยน 1 ตัวแปรเท่านั้น (ข้อความ / เวลา / offer / media)
3. รอ 24–48 ชม. (หรือจนถึงรอบซื้อ)
4. ตัดสินที่ RPM หรือ conversion ไม่ใช่ open rate
5. ต่างกัน < 10% = ไม่ต่าง (อย่าเปลี่ยน)
6. บันทึกผลลง change log
```

**ลำดับการทดสอบที่ควรทำ**
```
เดือน 1  เวลาส่ง
เดือน 2  ความยาวข้อความ / จำนวน bubble
เดือน 3  ประเภท offer
เดือน 4  media (ภาพ vs วิดีโอ)
เดือน 5  CTA wording
```

## กับดักของบทนี้

- ❌ เริ่มแก้ที่ content เมื่อตัวเลขยังไม่น่าเชื่อถือ
- ❌ เปลี่ยน 3 อย่างพร้อมกันแล้วสรุปว่าอะไรทำงาน
- ❌ วัดผลใน 2 ชั่วโมง
- ❌ ไม่มี baseline → ไม่รู้ว่าดีขึ้นหรือแย่ลง
- ❌ ตัดสินจาก open rate ที่ขึ้นแต่ยอดไม่ขึ้น
- ❌ ไม่บันทึกการเปลี่ยนแปลง → หาสาเหตุไม่ได้
