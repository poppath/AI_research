# Metrics · Creative production

| Metric | สูตร | ข้อควรระวัง |
|---|---|---|
| Cost per qualified purchase | ad spend / qualified purchases ตามนิยามที่บันทึก | ระบุ event, window และ refunds; zero = N/A |
| CM3/order | CM2 ต่อ order − ค่าโฆษณาต่อ order | ไม่เท่ากำไรสุทธิ; แยกช่องทาง SKU และช่วงเวลา |
| CTR | clicks ที่ระบุชนิด / impressions | CTR ไม่ใช่การซื้อ; ใช้ numerator ตาม platform |
| Hook rate | จำนวน video starts ผ่านเกณฑ์เวลาที่ระบุ / denominator ที่ระบุ | platform definitions ต่างกัน เปรียบเทียบเมื่อเหมือนกันเท่านั้น |
| QA pass | approved assets / assets ที่ส่งตรวจ | นับ revision และประเภท defect แยก |
| Cycle time | approval timestamp − brief accepted timestamp | ระบุ calendar หรือ working time |
| Refund/complaint rate | จำนวน refund/complaint ตามนิยาม / qualified orders | cohort/lag ต้องสอดคล้อง |

ทุก KPI มี owner, timeframe, market, baseline และ threshold ที่ตั้งล่วงหน้า; ไม่มี universal benchmark ในชุดนี้
