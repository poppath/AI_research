# 04 · ระบบผลิตครีเอทีฟด้วย AI (Creative Production System)

> **Review 7 พ.ย. 2026:** เอกสารเดิมเป็น research snapshot มีตัวเลข/heuristic และข้ออ้างที่ยังต้องตรวจรายกรณี ไม่ใช่กฎสากลหรือ rate ปัจจุบัน; ก่อนใช้ให้ดู [ข้อจำกัดและรายการแก้ไข](../../../REPO-REVIEW-2026-11-07.md) และ `AGENTS.md` โดยเฉพาะก่อนตัดสินใจงบ กฎหมาย หรือ automation.

> หลักคิด: **AI ไม่ได้ทำให้ครีเอทีฟดีขึ้น — AI ทำให้ "จำนวน variant" เพิ่มขึ้น** ความได้เปรียบจึงมาจาก *คุณภาพของ concept* และ *วินัยในการทดสอบ* ไม่ใช่จากเครื่องมือ

## 1. ทำไมครีเอทีฟคือ targeting ในปี 2026

Andromeda อ่านเนื้อหาแอด (ภาพ, ข้อความ, เสียง) แล้วจับคู่กับคนที่มีแนวโน้มตอบสนองสูงสุด ดังนั้น:

| ถ้าคุณทำ... | ระบบจะ... | ผลลัพธ์ |
|---|---|---|
| ครีเอทีฟ 10 ชิ้นที่ต่างกันแค่สีพื้นหลัง | มองเป็นชิ้นเดียว | เรียนรู้ช้า, fatigue เร็ว |
| ครีเอทีฟ 10 ชิ้นที่ต่าง persona/angle | แยกกลุ่มผู้ชมได้ | เรียนรู้เร็ว, หาคนใหม่ได้ |
| ครีเอทีฟชิ้นเดียว + interest 10 ชั้น | จำกัดตัวเอง | CPM สูง, reach แคบ |

**นิยาม "creative diversity" ที่ใช้ได้จริง** = ต่างกันอย่างน้อย 2 ใน 4 มิติ: *persona · awareness level · angle · format*

## 2. Concept Matrix (3 × 3 × 3)

### 2.1 แกนที่ 1: Persona (ใคร)
เลือก 3 persona ที่มี "แรงจูงใจต่างกันจริง" ไม่ใช่แค่ demographics ต่าง

| Persona | แรงจูงใจ | สิ่งที่ทำให้ซื้อ | สิ่งที่ทำให้ไม่ซื้อ |
|---|---|---|---|
| P1: ผู้เริ่มต้น | กลัวทำผิด | คำอธิบายง่าย + การรับประกัน | ศัพท์เทคนิค |
| P2: ผู้เปรียบเทียบ | อยากได้คุ้มที่สุด | ตารางเทียบ + ราคาโปร่งใส | การขายแบบเร่งเร้า |
| P3: ผู้มีประสบการณ์ | อยากได้ของที่ดีกว่า | หลักฐานเชิงเทคนิค + รีวิวผู้ใช้ระดับเดียวกัน | คำโฆษณาเกินจริง |

### 2.2 แกนที่ 2: Awareness Level (รู้แค่ไหน)
ตามกรอบ 5 ระดับ (unaware → problem-aware → solution-aware → product-aware → most-aware)

| ระดับ | สิ่งที่ต้องพูด | ฟอร์แมต |
|---|---|---|
| Unaware | เล่าเรื่อง/สถานการณ์ที่คนดู "ใช่เลย" | Reels เรื่องสั้น |
| Problem-aware | ตั้งชื่อปัญหาให้ชัด | Reels + hook คำถาม |
| Solution-aware | อธิบายกลไกที่ทำให้ต่าง | วิดีโอสาธิต 15–30 วิ |
| Product-aware | เปรียบเทียบ + ราคา + หลักฐาน | carousel / ตารางเทียบ |
| Most-aware | offer + urgency | Stories / retargeting |

### 2.3 แกนที่ 3: Angle (พูดแง่มุมไหน)
เลือก 3 angle ต่อ persona: เช่น **ประโยชน์ตรง / ลบความกลัว / social proof** หรือ **ประหยัดเวลา / ประหยัดเงิน / สถานะ**

### 2.4 ตารางผลลัพธ์: 3 × 3 × 3 = 27 concepts → เลือก 12–15 ชิ้นลงจริง

| # | Persona | Awareness | Angle | Format | Hook (สรุป) |
|---|---|---|---|---|---|
| 1 | P1 ผู้เริ่มต้น | Problem | ลบความกลัว | Reels 9:16 | "กลัวทำพลาด? 3 ข้อนี้ช่วยได้" |
| 2 | P1 | Solution | ประหยัดเวลา | Reels | "ปกติใช้ 2 ชั่วโมง เหลือ 10 นาที" |
| 3 | P2 ผู้เปรียบเทียบ | Product | ประหยัดเงิน | Carousel 4:5 | "เทียบ 3 เจ้าให้แล้ว" |
| 4 | P2 | Most-aware | offer | Stories | "เหลือ 2 วัน" |
| 5 | P3 ผู้มีประสบการณ์ | Solution | เทคนิค | วิดีโอสาธิต | "ทำไม___ถึงต่าง" |
| … | | | | | |

> **กติกา**: อย่าลงครีเอทีฟที่ "หน้าตาต่างแต่สารเดียวกัน" เกิน 3 ชิ้น — ให้ถือเป็น variant เดียว

## 3. Hook Library (ภาษาไทย ใช้ได้เลย)

### 3.1 Hook 7 ตระกูล

| ตระกูล | สูตร | ตัวอย่าง |
|---|---|---|
| ปัญหา | "ถ้าคุณ___ แปลว่าคุณกำลัง___" | "ถ้าซื้อของออนไลน์แล้วโดนแบบนี้ แปลว่าคุณกำลังเสียเงินฟรี" |
| คำเตือน | "อย่า___ก่อน___" | "อย่าจองโรงแรมก่อนดู 3 ข้อนี้" |
| คำถาม | "ทำไม___?" | "ทำไมคนซื้อซ้ำถึงไม่ซื้อแบบเดิม?" |
| ตัวเลข | "___% ของคน___" | "80% ของคนที่ลองแล้วเลิก เพราะข้อเดียว" |
| ก่อน/หลัง | "จาก___ สู่___ ใน___" | "จากยอด 0 สู่ 200 ออเดอร์ใน 30 วัน" |
| POV/เรื่องเล่า | "POV: คุณ___" | "POV: คุณเปิดร้านใหม่แล้วไม่มีคนเห็น" |
| ตรงข้ามความเชื่อ | "ทุกคนบอกให้___ แต่จริง ๆ ___" | "ทุกคนบอกให้ยิงแอดกว้าง แต่จริง ๆ ต้อง..." |

### 3.2 กติกา hook
- **≤ 8 คำ** สำหรับข้อความบนจอ, **≤ 2 วินาที** สำหรับคำพูด
- ต้องทำงานได้ทั้ง **เสียงปิด** และ **เสียงเปิด**
- ห้ามใช้ hook ที่ไม่ได้สัญญาอะไรกับเนื้อหาข้างใน (clickbait ทำให้ retention พัง → CPM สูงขึ้น)
- Hook เดียวกันใช้ซ้ำได้กับคนละ angle แต่ไม่ควรเกิน 3 ชิ้น

## 4. สคริปต์ Reels 15 วินาที (เทมเพลต)

```
[0:00–0:02] HOOK
  ภาพ: ______ (หน้าคน / มือกำลัง___ / before-after)
  ข้อความบนจอ: ______ (≤ 8 คำ)
  เสียง: ______ (ประโยคเดียว)

[0:02–0:05] PROBLEM
  ภาพ: ______
  เสียง: "ส่วนใหญ่______ แต่จริง ๆ ______"

[0:05–0:10] PROOF / DEMO
  ภาพ: ______ (สาธิต 2–3 ช็อต)
  ข้อความ: ตัวเลข/ผลลัพธ์
  เสียง: อธิบายกลไก 1 ประโยค

[0:10–0:13] OFFER
  ข้อความ: ราคา/โปร/การรับประกัน
  เสียง: "ตอนนี้______"

[0:13–0:15] CTA
  ข้อความ: "กดดูรายละเอียด"
  โลโก้ (มุมบนซ้าย ไม่ทับ safe zone)
```

**ข้อกำหนดทางเทคนิค**: 9:16, subtitle ฝัง, ข้อความอยู่ใน safe zone, ความยาว 12–18 วิ, ไฟล์ < 4 GB, 30 fps

## 5. Production Pipeline ด้วย AI (5 ขั้น)

```
[1] INSIGHT      → LLM สรุป pain point/ภาษา/objection จากรีวิว, คอมเมนต์, แชท, เสิร์ช
[2] CONCEPT      → 3×3 matrix + hook
[3] SCRIPT       → สคริปต์ 15/30 วิ + copy 3 ความยาว
[4] ASSET        → ภาพ / วิดีโอ / เสียง / UGC avatar
[5] QA + ADAPT   → ตรวจแบรนด์ + safe zone + 9:16 / 4:5 / 1:1 + subtitle
```

### 5.1 เครื่องมือแยกตามงาน

| งาน | เครื่องมือที่ใช้ได้ | หมายเหตุ |
|---|---|---|
| วิจัย/สรุป insight | ChatGPT, Claude, Gemini (อัปโหลดรีวิว/คอมเมนต์) | ต้องมีข้อมูลจริงจำนวนมากพอ |
| เขียน hook/copy (ไทย) | LLM + prompt library | ตรวจคำซ้ำ/น้ำเสียงแบรนด์ |
| ภาพนิ่ง | Midjourney, Flux, Firefly, Muse Image (ใน Meta) | **ข้อความไทยในภาพมักเพี้ยน → ใส่ข้อความด้วย editor** |
| วิดีโอสั้น | Runway, Kling, Veo, Sora, Meta image-to-video | ตรวจความต่อเนื่องของมือ/หน้า/สินค้า |
| UGC avatar | HeyGen, Arcads, Creatify | ต้องมี disclosure ว่า AI |
| เสียง/พากย์ | ElevenLabs, Meta AI dubbing | ภาษาไทยต้องตรวจการออกเสียงชื่อแบรนด์ |
| ตัดต่อ/ซับ | CapCut, Descript, Adobe | ใส่ safe zone overlay |
| ทดสอบครีเอทีฟ | Meta A/B test, Marpipe, Superads | 1 ตัวแปร/ครั้ง |
| ตรวจ compliance | LLM + checklist | ห้ามฝาก AI ตัดสินใจด้านกฎหมายเพียงลำพัง |

### 5.2 ข้อจำกัดที่ต้องรู้ (สำคัญมากสำหรับภาษาไทย)

1. **AI ภาพเขียนภาษาไทยไม่ถูก** — ให้สร้างภาพเปล่า แล้วใส่ข้อความด้วย Figma/Canva/CapCut
2. **มือ/นิ้ว/สินค้าเพี้ยน** — ตรวจทุกภาพก่อนใช้ โดยเฉพาะสินค้าที่มีรายละเอียด
3. **AI avatar ดู "เกือบจริง"** — ถ้าแบรนด์เน้นความน่าเชื่อถือ ให้ใช้คนจริงในฉากจริง หรือติด disclosure ชัด
4. **เสียงพากย์ไทยยังมีสำเนียง** — ทดสอบกับคนไทย 3–5 คนก่อนใช้ในแคมเปญใหญ่
5. **AI copy ชอบใช้คำซ้ำ/ superlative** — ต้องมี brand tone guide และ banned words list
6. **อย่าให้ AI สร้างข้อความรับรอง (testimonial) ปลอม** — ผิดทั้งกฎหมายและจริยธรรม

## 6. Creative Volume & Refresh Plan

| ระดับรายจ่าย/เดือน | concepts ใหม่/เดือน | variants/เดือน | refresh |
|---|---|---|---|
| < 50,000 THB | 4–6 | 12–18 | ทุก 3–4 สัปดาห์ |
| 50,000–200,000 | 8–12 | 30–50 | ทุก 2–3 สัปดาห์ |
| 200,000–500,000 | 12–20 | 60–100 | ทุก 2 สัปดาห์ |
| > 500,000 | 20–30 | 120+ | ทุก 1–2 สัปดาห์ |

**สัญญาณว่า fatigue** (เข้าเกณฑ์ใดเกณฑ์หนึ่ง):
- Frequency > 3 ใน 7 วัน
- CTR ลด > 25% จากสัปดาห์ก่อน ขณะที่ CPM ทรงตัว
- CPA เพิ่ม > 20% ต่อเนื่อง 3 วัน
- Hook rate (3-sec views / impressions) ลดต่อเนื่อง

**วิธี refresh**: เปลี่ยน *hook* ก่อน (ถูกที่สุด) → เปลี่ยน *หลักฐาน* → เปลี่ยน *angle* → เปลี่ยน *persona* (แพงที่สุด)

## 7. AI + มนุษย์: ใครทำอะไร

| ขั้น | AI ทำ | คนทำ |
|---|---|---|
| วิจัย | สรุป/จัดกลุ่ม/หา pattern | เลือก insight ที่ "จริง" และสำคัญ |
| Concept | เสนอทางเลือก 20 แบบ | เลือก 3 ที่ตรงแบรนด์ + มีโอกาส |
| Script | ร่าง | เกลาเสียงภาษา + ตรวจข้อเท็จจริง |
| Asset | ผลิต variant | ตรวจคุณภาพ/แบรนด์/กฎหมาย |
| Launch | ตั้งค่า/จัดกลุ่ม | ตัดสินใจโครงสร้าง + งบ |
| Optimize | วิเคราะห์/เสนอ | อนุมัติ + รับผิดชอบผล |
| Learn | สรุปบทเรียน | ยืนยันว่าบทเรียนถูกต้อง |

> **เส้นแบ่งที่ห้ามข้าม**: AI ไม่มีสิทธิ์ (1) เพิ่มงบเองเกินเพดาน (2) เปลี่ยนข้อความที่มีผลทางกฎหมาย (3) สร้างรีวิว/ใบรับรองปลอม (4) ลบข้อมูลการทดลอง

## 8. Brand Safety & Disclosure

- ใช้ **brand kit** (โลโก้/สี/ฟอนต์) ก่อนเปิด creative automation
- เนื้อหาที่สร้างด้วย AI ควรมี label ตามข้อกำหนดของแพลตฟอร์ม และตามนโยบายแบรนด์
- หลีกเลี่ยง: ภาพบุคคลเหมือนจริงที่ไม่ได้ยินยอม, การเลียนแบบ celeb, ข้อความสุขภาพ/การเงินที่ไม่มีหลักฐาน
- เก็บ "source of truth" ของ asset (ไฟล์ตั้งต้น + prompt) ไว้เพื่อการตรวจสอบย้อนหลัง

## 9. Checklist QA ครีเอทีฟ (ก่อนส่งเข้าแคมเปญ)

- [ ] 9:16 / 4:5 / 1:1 ครบตาม placement ที่ตั้ง
- [ ] ข้อความสำคัญอยู่ใน safe zone (บน 14% / ล่าง 35% / ข้าง 6%)
- [ ] Subtitle ฝังในวิดีโอ และอ่านได้บนมือถือ
- [ ] Hook ≤ 2 วิ, ทำงานได้ทั้ง sound-on/off
- [ ] โลโก้ ≥ 1 จุด, CTA ชัด
- [ ] ราคา/โปร/เงื่อนไข ตรงกับหน้าเว็บ
- [ ] ไม่มีข้อความรับรอง/ตัวเลขที่ไม่มีหลักฐาน
- [ ] ภาษาไทยไม่มีคำผิด/วรรณยุกต์เพี้ยน
- [ ] ไฟล์ตามสเปก (size, fps, bitrate, ≤ 4 GB)
- [ ] ชื่อไฟล์ตาม convention (`templates/campaign-naming.md`)
- [ ] ลงทะเบียน variant ใน experiment log
