# Metrics · Research & positioning

ตัวชี้วัดทุกตัวต้องมี timeframe, population และ source; ไม่มี universal target ที่อ้างว่าใช้ได้ทุกธุรกิจ

| Metric | นิยาม/วิธีใช้ | ระวัง |
|---|---|---|
| Recruitment yield | completed interviews / invited ที่มี eligibility ชัดเจน | ระบุช่องทางและ nonresponse; ไม่ใช่ prevalence |
| Evidence coverage | hypotheses ที่มีหลักฐานตรวจสอบย้อนกลับ / hypotheses ทั้งหมด | หลักฐานอาจขัดกันและไม่พิสูจน์ causality |
| Claim verification | claims ที่ proof และ approver ครบ / claims ที่จะเผยแพร่ | ไม่มี proof = block ไม่เฉลี่ยเป็น pass |
| Test outcome | ตาม primary KPI ที่ลงทะเบียนก่อนเริ่ม | แยก exploratory vs randomized; บอก uncertainty |
| CM3/order | CM2/order ลบค่าโฆษณาต่อ order ตาม definition ใน profit playbook | ระบุ timeframe / attribution / refunds |

หาก denominator = 0 ให้รายงาน N/A ไม่ใช่ 0%; ตั้งเกณฑ์ก่อน test ตามต้นทุน ความเสี่ยง และพลังการทดลอง
