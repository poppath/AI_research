# 05 · LIVE Commerce

> **Review 7 พ.ย. 2026:** เอกสารเดิมเป็น research snapshot มีตัวเลข/heuristic และข้ออ้างที่ยังต้องตรวจรายกรณี ไม่ใช่กฎสากลหรือ rate ปัจจุบัน; ก่อนใช้ให้ดู [ข้อจำกัดและรายการแก้ไข](../../REPO-REVIEW-2026-11-07.md) และ `AGENTS.md` โดยเฉพาะก่อนตัดสินใจงบ กฎหมาย หรือ automation.

> **TL;DR** — LIVE คือที่ที่ TikTok ได้เปรียบที่สุดในไทย แต่ก็เป็นที่ที่คนเผาเงินมากที่สุด เพราะมันไม่ใช่ "โฆษณา" แต่มันคือ **รายการทีวียอดขาย** ที่ต้องมีพิธีกร, สคริปต์, สินค้าพร้อม, และคอขวด logistics. กติกา: **อย่าเปิด LIVE ก่อนมีฐาน GMV จาก affiliate+ads** และ **LIVE GMV Max ต้องเปิดล่วงหน้า ≥3 วัน**

---

## 1. LIVE คุ้มจริงไหม — ตัดสินจาก 5 ตัวเลขนี้ก่อน

| ตัวเลข | เกณฑ์ตัดสิน |
|---|---|
| Avg watch time | 3–5 นาที = ดี · 8+ นาที = ยอดเยี่ยม |
| Live CVR (ซื้อ/ผู้ชม) | 1.5–3% = ดี · 8–12% = ยอดเยี่ยม |
| Engagement rate | 5–10% = ดี · 15%+ = ยอดเยี่ยม |
| GMV/session | $500–2,000 = ปกติ · $5,000+ = ดี |
| Return rate ของสินค้าที่ไลฟ์ | ถ้าสูงกว่าปกติชัด = ขายด้วย impulse เกินไป |

> ถ้า 3 ใน 5 ตัวต่ำกว่าเกณฑ์ → ปัญหาอยู่ที่ **สินค้า/พิธีกร/สคริปต์** ไม่ใช่งบ ads

---

## 2. LIVE Shopping Ads vs LIVE GMV Max

| | LIVE Shopping Ads | LIVE GMV Max |
|---|---|---|
| เหมาะกับ | แบรนด์ที่ต้องการคุมการโปรโมตอีเวนต์ | แบรนด์ที่พร้อมให้ AI จัดสรร |
| Input หลัก | คุณภาพไลฟ์, audience, creative, targeting, budget | สัญญาณการขายในไลฟ์ + สินค้า + shop |
| บทบาทของคุณ | วางแผนอีเวนต์, audience, งบ | ตั้ง guardrail เรื่องสินค้าและ margin ก่อน |
| ความเสี่ยง | ตั้งมืออาจ under-scale ไลฟ์ที่ดี | automation อาจไล่ GMV โดยไม่ดู margin |
| Learning | ~40 conversions | reset ทุกครั้งที่ไลฟ์ → ต้องไลฟ์ถี่และตรงเวลา |

**ตัวเลขไทย (vendor):**
- LIVE Shopping Ads: CPC ฿1–3, CPM ฿50–150 (ถูกกว่า shopping ปกติ 30–50%)
- งบไลฟ์มักเป็น 2–3× งบ shopping ปกติ
- งบขั้นต่ำ ฿500/วัน (campaign), ฿50/วัน (ad group)

## 3. ก่อนไลฟ์: checklist ที่พลาดบ่อย

### 3.1 สินค้า
- [ ] 3–5 สินค้าที่ "พร้อมไลฟ์" — margin ดี, stock ลึก, เห็นภาพชัด, มีรีวิว
- [ ] เรียงลำดับการขาย: **hero (ดึงคน) → volume (ทำยอด) → profit (ทำกำไร) → bundle**
- [ ] ตั้งราคา/coupon เฉพาะไลฟ์ (urgency จริง ไม่ใช่ของปลอม)
- [ ] กำหนด inventory limit ต่อสินค้า (กัน oversell)

### 3.2 คน
- [ ] พิธีกร 1–2 คน (คนขาย + คนแชท)
- [ ] host brief: จุดขาย 3 ข้อ, objection 5 ข้อ + คำตอบ, FAQ, ช่วงเวลา urgency
- [ ] ซ้อม 30 นาทีก่อนไลฟ์จริง (โดยเฉพาะการสลับสินค้า/ราคา)

### 3.3 ห้อง
- [ ] แสง 2–3 điểm (key + fill + หลัง), กล้อง 1080p, ไมค์ lapel
- [ ] ฉากหลังสะอาด, มีป้าย/ราคา
- [ ] เน็ตสำรอง (hotspot 4G)
- [ ] จอที่เห็นคอมเมนต์แบบเรียลไทม์

### 3.4 เทคนิค
- [ ] ตั้งชื่อ session ที่มี keyword (`#เสื้อผ้าไซส์ใหญ่ ไลฟ์ลด 50%`)
- [ ] เตรียม "ลูป" เนื้อหา 20–30 นาที (เพราะคนเข้าออกตลอด)
- [ ] เตรียม giveaway ทุก ~30 นาทีเพื่อรีเทนชัน

## 4. โครงสร้างไลฟ์ 120 นาที (ที่ใช้ได้จริง)

| นาที | ช่วง | เป้าหมาย |
|---|---|---|
| 0–10 | **Hook & promise** | บอกว่าวันนี้มีอะไร ลดเท่าไหร่ ของแถมอะไร (ทำซ้ำทุก 20 นาที) |
| 10–30 | **Hero demo** | สาธิตสินค้าตัวหลักให้เห็นผลจริง (before/after, ใช้งาน) |
| 30–40 | **Flash deal #1** | สร้าง urgency, เก็บ spike แรก |
| 40–70 | **Volume block** | สินค้าขายดี 3–5 ตัว, สลับทุก 8–10 นาที |
| 70–80 | **Q&A + objection handling** | ตอบข้อสงสัยที่ถูกถามซ้ำ ๆ |
| 80–100 | **Bundle / set** | เพิ่ม AOV |
| 100–110 | **Flash deal #2** | spike ที่สอง |
| 110–120 | **Close & next-tease** | บอกไลฟ์หน้าวันไหน มีอะไร (สร้างการกลับมา) |

**กติกาความถี่:** สัปดาห์ละ 1–2 ครั้ง × 2–4 ชั่วโมง ก่อน; เพิ่มเป็น 3–5 ครั้ง/สัปดาห์เมื่อพิสูจน์แล้วว่า CM positive. **LIVE GMV Max เปิดล่วงหน้า ≥3 วัน และต้องรัน ≥3 วัน**

## 5. ระหว่างไลฟ์: ตัวเลขที่ต้องจับตา

| ตัวเลข | ถ้าต่ำ | ทำอะไรทันที |
|---|---|---|
| Concurrent viewers | <10 | โยน traffic (LIVE ads/boost), ประกาศ giveaway |
| Avg watch time | <2 นาที | เปลี่ยนกิจกรรม, ตัดช่วงที่พูดคนเดียวนาน |
| Add-to-cart rate | <5% | โชว์ราคาชัดขึ้น, พูด coupon ให้ชัด |
| Comment rate | ต่ำ | ถามคำถามตรง ๆ, poll |
| Conversion ช่วง flash | ต่ำ | ตรวจราคา/stock ผิดหรือเปล่า |

---

## 6. หลังไลฟ์: สิ่งที่ต้องตัดสินใจเพื่อให้ครั้งหน้าดีขึ้น

ทำทุกครั้งภายใน 24 ชม.:
1. **ตัดคลิป highlight 5–10 ชิ้น** → ใช้เป็น creative/ad ต่อ (นี่คือ ROI ที่ซ่อนอยู่ของ LIVE)
2. **ระบุช่วงเวลาที่คนซื้อมากสุด** → ทำซ้ำในไลฟ์หน้า
3. **เก็บ objection ที่ถูกถาม** → ใส่หน้า product page
4. **คำนวณ CM ต่อ session** (ไม่ใช่ GMV) — รวม commission, coupon, ads, return
5. **อัปเดตสคริปต์**: เพิ่ม 1 ช่วงที่ work, ตัด 1 ช่วงที่ตาย

## 7. LIVE 90-day roadmap

| ช่วง | โฟกัส | เป้า |
|---|---|---|
| Day 1–30 | 1–2 ไลฟ์/สัปดาห์, 2 ชม., 3–5 สินค้า | รู้ว่าสินค้า/พิธีกร/ช่วงเวลาไหน work |
| Day 31–60 | 2–3 ไลฟ์/สัปดาห์, LIVE Shopping Ads, ทดสอบ host/เวลา | CVR ↑, watch time ↑, CM ≥ 0 |
| Day 61–90 | 3–5 ไลฟ์/สัปดาห์, LIVE GMV Max, creator-host collab | GMV/session ↑, return คุมได้ |

## 8. Anti-patterns

| ❌ | ผล | ✅ |
|---|---|---|
| ไลฟ์ 8 ชั่วโมงตั้งแต่วันแรก | พิธีกรหมดเสียง, คุณภาพตก | 2 ชม. × 2 ครั้ง/สัปดาห์ |
| ไลฟ์โดยไม่มี offer | ไม่มีเหตุผลให้ซื้อตอนนี้ | coupon เฉพาะไลฟ์ |
| พูดคนเดียว ไม่ตอบคอมเมนต์ | watch time ตก | 1 คนขาย + 1 คนแชท |
| ไม่โปรโมตไลฟ์ล่วงหน้า | คนดู 5 คน | ประกาศ 3 วันล่วงหน้า + LIVE ads |
| เปิด LIVE GMV Max วันที่ไลฟ์ | ไม่ทัน learning | เปิดล่วงหน้า ≥3 วัน |
| วัดผลด้วย GMV | ขาดทุนไม่รู้ตัว | CM after all costs |
| ไม่ตัดคลิปหลังไลฟ์ | ทิ้งเนื้อหาฟรี | ตัด 5–10 คลิป ทุกครั้ง |
