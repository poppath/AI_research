# 09 · Organic × Paid Flywheel

> **Review 7 พ.ย. 2026:** เอกสารเดิมเป็น research snapshot มีตัวเลข/heuristic และข้ออ้างที่ยังต้องตรวจรายกรณี ไม่ใช่กฎสากลหรือ rate ปัจจุบัน; ก่อนใช้ให้ดู [ข้อจำกัดและรายการแก้ไข](../../REPO-REVIEW-2026-11-07.md) และ `AGENTS.md` โดยเฉพาะก่อนตัดสินใจงบ กฎหมาย หรือ automation.

> **TL;DR** — ออร์แกนิกบน TikTok ไม่ใช่ "งานแบรนด์" แยกจาก performance — มันคือ **โรงงานวัตถุดิบของ paid**. แบรนด์ที่รัน Spark Ads คู่กับโพสต์ออร์แกนิกมี organic reach สูงกว่าแบรนด์ที่ทำออร์แกนิกอย่างเดียว ~28% [tiktok via vendor]. ลงทุนออร์แกนิก = ลด CAC ของ paid

---

## 1. กลไกที่ทำให้ออร์แกนิกช่วย paid

```
โพสต์ออร์แกนิก
   ↓ (มี engagement จริง = social proof)
Spark Ads boost
   ↓ (คนใหม่เข้ามาที่โปรไฟล์)
คนใหม่ดูออร์แกนิกอื่น
   ↓ (signal บวกให้ algorithm)
ออร์แกนิกได้ reach เพิ่ม (ฟรี)
   ↓
วัตถุดิบใหม่สำหรับ paid (คลิปที่ work แล้ว)
```

**สิ่งที่ TikTok ไม่ทำ:** การยิงแอดไม่ได้ boost ออร์แกนิกโดยตรง — มัน boost ทางอ้อมผ่านคนดูใหม่ที่มา engage

---

## 2. Algorithm 2026 — สัญญาณที่ต้องเล่นด้วย

| Signal | น้ำหนัก (ประมาณ) | แปลว่าต้องทำอะไร |
|---|---|---|
| **Watch time / completion rate** | 40–50% | ตัดให้แน่น, hook 1–3 วิ, 70%+ completion คือบาร์ |
| **Rewatches / loops** | สูง | ทำคลิป loopable (จบแล้วต่อต้นได้) |
| **Shares** | สูง | ทำคอนเทนต์ที่ "ต้องส่งให้เพื่อน" |
| **Saves** | สูง | ทำคอนเทนต์ที่มีประโยชน์อ้างอิงได้ (how-to, list) |
| **Comments** | กลาง | ถามคำถามที่ทำให้อยากตอบ |
| **Likes** | ต่ำ (ลดลง) | อย่าวัดด้วยไลก์ |
| **Follows จากวิดีโอ** | กลาง | บอกให้ชัดว่า "มีอะไรอีก" |

**การกระจายตัว (batch testing):**
```
Wave 1  ~200-500 views   → ทดสอบกับ follower ก่อน (24-72 ชม.แรก)
Wave 2  1k-50k           → ขยายไปคนที่ behavior คล้ายกัน
Wave 3  50k-500k         → FYP หลัก (saves + shares กลายเป็นตัวชี้ขาด)
Wave 4  500k+            → ข้ามกลุ่มประชากร/ภูมิภาค
```
> ถ้า Wave 1 ไม่ผ่าน = "ติดคุก 200 วิว" → ปัญหาอยู่ที่ hook หรือ retention ไม่ใช่จำนวน follower

## 3. ตัวเลข cadence ที่ใช้ได้จริง

| ตัวเลข | ค่า | หมายเหตุ |
|---|---|---|
| โพสต์/สัปดาห์ (แบรนด์) | **4–7** | optimal range |
| โพสต์/สัปดาห์ ที่ให้ผลเพิ่ม | 3–5/สัปดาห์ ให้ views +17–29% vs 1/สัปดาห์ | [vendor] Buffer 11M+ videos |
| 11+/สัปดาห์ | views +34% | แต่เกิน 3–4/วันเริ่ม diminishing |
| ช่วง 30 วันแรก (establish signals) | 5–7/สัปดาห์ | ต้องมี volume ให้ algorithm เรียนรู้ |
| วันที่ 31–60 | 4–5/สัปดาห์ | เปลี่ยนจาก volume → quality |
| วันที่ 61–90 | 3–5/สัปดาห์ | quality + intent ต่อโพสต์ |
| เกิน 1 โพสต์/วัน | performance เฉลี่ยต่อคลิปมักลดลง | ยกเว้นมีทีมผลิตจริงจัง |

**สำคัญ:** algorithm ดู pattern 30 วัน — โพสต์ 2 คลิป/วันติดกัน 30 วันได้ผลดีกว่าโพสต์ 14 คลิปวันเดียวแล้วหายไป 2 สัปดาห์

## 4. ระบบคอนเทนต์ 70/20/10

| สัดส่วน | ประเภท | ทำไม |
|---|---|---|
| **70%** | ให้ความรู้ / บันเทิง (สร้างความเชื่อใจ + audience) | ลด ad fatigue, ให้วัตถุดิบ paid ที่ดู native |
| **20%** | Engagement (poll, คำถาม, challenge, ตอบคอมเมนต์) | ดึงคอมเมนต์/shares |
| **10%** | ขายตรง (CTA, โปรโมชัน) | ไม่ให้ feed กลายเป็น catalog |

**สูตรที่ใช้ได้จริงกับแบรนด์สินค้า:** ทำ 70% เป็น "ปัญหา → วิธีแก้" ที่ไม่พูดถึงสินค้าเลย แล้วอีก 30% พูดสินค้า → คลิป 70% พวกนี้มักเป็นตัวที่ใช้เป็น Spark Ads ได้ดีที่สุด (soft sell)

## 5. Spark Ads: จุดเชื่อม organic ↔ paid

| ขั้นตอน | รายละเอียด |
|---|---|
| 1 | เลือกโพสต์ที่ organic performance ดี (ไม่ใช่แค่ยอดไลก์ — ดู saves/shares/completion) |
| 2 | ของแบรนด์เอง: boost จาก Ads Manager ได้เลย; ของครีเอเตอร์: ขอ **authorization code** (อายุ ~30 วัน) |
| 3 | ตั้งเป็น ad ใน ad group ปกติ (Spark เป็น format ไม่ใช่ campaign type) |
| 4 | วัด: เทียบ Spark vs in-feed creative เดียวกัน |

**ตัวเลข:** Spark Ads completion +134%, CVR +69% เทียบ in-feed [vendor TH]; engagement lift 2.4× [vendor]

**ข้อควรระวัง:** ถ้าครีเอเตอร์พูด claim เกินกฎหมายในคลิปนั้น แอดที่ boost ก็ติดไปด้วย → ต้อง review ทุกคลิปก่อน boost (บท 10)

## 6. Creator program ที่ป้อนทั้ง organic และ paid

```
Tier A · Affiliate/TAP (15-75 คน)   → ผลิตคอนเทนต์เชิงขาย + GMV Max
Tier B · UGC creators (5-15 คน)      → คลิปสำหรับ Spark Ads โดยเฉพาะ
Tier C · Micro-KOL (3-5 คน)          → สร้าง credibility + reach
Tier D · Brand account               → คอนเทนต์ 70/20/10 + ตอบคอมเมนต์
```

**กติกาการจ่าย:**
- Tier B: จ่ายต่อคลิป + โบนัสถ้าคลิปถูกใช้ใน paid (เพราะนั่นคือมูลค่าจริง)
- ทุกสัญญาต้องมี **usage rights** ชัดเจน (ระยะเวลา, ช่องทาง, การดัดแปลง, Spark authorization)
- อย่าให้ creator ถือสิทธิ์ veto การใช้ใน paid — ต่อรองตั้งแต่ต้น

## 7. Comment & community — leverage ที่ฟรี

- **ตอบคอมเมนต์ทุกอันใน 2 ชั่วโมงแรก** → ดัน engagement velocity
- **ใช้คอมเมนต์เป็นไอเดียคอนเทนต์** (ตอบด้วยวิดีโอ = เนื้อหาฟรีที่ validated by demand)
- **ปักหมุดคอมเมนต์** ที่มีคำถามที่พบบ่อย (ลด objection ที่หน้าเว็บ)
- comment mining = keyword research ที่ถูกที่สุด (บท 06)

## 8. TikTok SEO สำหรับออร์แกนิก (ทำคู่กับ paid)

1. 1 คลิป = 1 search phrase (พูดบนเสียง + เขียนบนจอ + ใน caption)
2. ใส่ 1–3 hashtag ที่ตรง (broad 1 + niche 1–2) — hashtag สำคัญกับ search มากกว่า FYP
3. เปิด **Keyword Metadata Management** (เปิดเม.ย. 2026) เพื่อจัดการ keyword ที่ AI assigned ให้วิดีโอ
4. ใช้ **Creator Search Insights → Content Gap** หาเรื่องที่คนค้นแต่ยังมีคลิปน้อย
5. วิดีโอที่ติด search ทำงานต่อเนื่อง 4–8 สัปดาห์ขึ้นไป (compounding) vs FYP ที่จบใน 48 ชม.

## 9. ตาราง: ออร์แกนิกควรทำอะไรในแต่ละสถานะธุรกิจ

| สถานะ | โฟกัสออร์แกนิก | KPI |
|---|---|---|
| แบรนด์ใหม่ (0–1k followers) | volume + หา format ที่ work | completion rate, saves |
| เริ่มมี paid | ผลิตวัตถุดิบให้ Spark Ads | จำนวนคลิปที่ใช้ใน paid ได้/เดือน |
| กำลัง scale | 70/20/10 + topical authority | search impressions, share rate |
| Shop | affiliate + LIVE clips + search SEO | GMV จากออร์แกนิก, video-to-purchase rate |
| Brand mature | thought leadership + community | repeat purchase, branded search |

## 10. Anti-patterns

| ❌ | ผล |
|---|---|
| ดูถูกออร์แกนิกว่า "ของแถม" | ไม่มีวัตถุดิบ paid → ต้องผลิตใหม่ตลอด = แพง |
| โพสต์ตามอารมณ์ ไม่มีตาราง | algorithm ไม่ได้ pattern 30 วัน |
| ใช้ trending sound ที่ไม่มีสิทธิ์เชิงพาณิชย์ | แอดถูก reject / โดน mute |
| โพสต์แต่ขาย (100% direct) | engagement ตก, reach ตก |
| boost ทุกโพสต์เป็น Spark Ads | ไม่มีอะไรเหลือเป็น organic social proof |
| ไม่ตอบคอมเมนต์ | เสีย engagement velocity ฟรี ๆ |
| ทำคลิปยาวโดยไม่ดู completion | distribution ตก |
