# 03 · Creative System & Hook Engineering

> **TL;DR** — บน TikTok, creative คือ targeting. งานของคุณไม่ใช่ "ทำแอดสวย" แต่คือ **สร้างเครื่องจักรที่ผลิต hook ใหม่ ๆ ได้ทุกสัปดาห์ และรู้ภายใน 72 ชั่วโมงว่าตัวไหนชนะ**. ลงแรง 90% ที่ 1–3 วินาทีแรก, ปล่อยให้ AI ทำที่เหลือ

---

## 1. ทำไม creative ถึงคอขวด

บน automation era ปุ่มตั้ง targeting หายไปหมดแล้ว เหลือ 4 levers: **creative volume, creative diversity, product feed, offer** [vendor: adfirm]. และใน 4 อย่างนั้น creative เป็นตัวเดียวที่ผลิตเพิ่มได้ไม่จำกัด

| ข้อเท็จจริง | ตัวเลข | ที่มา |
|---|---|---|
| Concept หมดอายุบน TikTok | 10–14 วัน | [vendor] rocketshiphq |
| ระยะที่ควร refresh | ทุก 7–14 วันต่อ concept | [vendor] |
| จำนวน creative ที่ควรเพิ่ม/สัปดาห์ | 2–3 ชิ้น (ขั้นต่ำ), 10–15 ชิ้น (GMV Max scale) | [vendor] |
| ความยาวที่ completion ดีสุด | 9–15 วินาที | [vendor] mbadv / cometly |

| จำนวนที่ Smart+ ต้องการ | ≥6 ตอนสร้าง (TikTok), 5–10 diverse คือ sweet spot | [tiktok]/[vendor] |

## 2. กายวิภาคของ creative ที่ work

```
0-1s    HOOK VISUAL      ภาพ/การเคลื่อนไหวที่หยุดนิ้ว (ไม่ใช่โลโก้)
0-3s    HOOK LINE       ประโยค/ข้อความที่บอก "ทำไมต้องดูต่อ"
3-8s    VALUE           ประโยชน์เดียวที่ชัด (ไม่ใช่ 5 ข้อ)
8-13s   PROOF           ก่อน/หลัง, รีวิว, ตัวเลข, การใช้งานจริง
13-15s  CTA             ข้อความบนจอ + เสียง + ปุ่ม ใน safe zone
```

**ตัวเลขที่ต้องจำ:**

| Spec | ค่า |
|---|---|
| Aspect ratio | 9:16 (บังคับสำหรับ in-feed) |
| Resolution | 1080×1920 (ขั้นต่ำ 540×960) |
| Bitrate | ≥516 kbps (แนะนำ 8–12 Mbps ที่ 1080p) |
| File size | ≤500 MB (แนะนำ <200 MB) |
| Format | MP4 (H.264) / MOV |
| Safe zone | หลบขอบบน ~120–130 px, ล่าง ~480 px, ขวา ~140 px → เก็บของสำคัญใน 80% กลาง |
| Caption | ≤100 ตัวอักษร (เกินแล้ว TikTok ตัด "...") |
| จำนวน creative/ad group | 3–5 (manual) |

## 3. Hook Engineering — หัวใจของทั้งหมด

### 3.1 Hook ทำอะไร
hook ไม่ได้ทำหน้าที่ "ขาย" — มันทำหน้าที่ **ซื้อเวลา 3 วินาที**. การขายเกิดที่ 3–13 วินาที. ถ้า hook พยายามขายมากเกินไป (เช่นขึ้นชื่อแบรนด์+สโลแกน) คนจะปัดทิ้งเพราะสมองจำแนกได้ว่า "นี่คือโฆษณา"

### 3.2 Hook 8 แบบที่ใช้ได้จริง

| # | ประเภท | ตัวอย่าง | เหมาะกับ |
|---|---|---|---|
| H1 | Bold claim | "ตัวนี้ ฿290 ดีกว่าตัว ฿2,000 ที่ใช้อยู่" | สินค้าที่เทียบราคาได้ |
| H2 | Direct address (call-out) | "หยุดถ้าคุณผิวมันช่วงหน้าร้อน" | niche ที่แคบชัด |
| H3 | Curiosity gap | "รอจนเห็นนาทีที่ 8" | transformation/reveal |
| H4 | Problem-first | "เสื้อผ้าเหม็นอับเพราะเครื่องซักผ้า ไม่ใช่ผงซักฟอก" | สินค้าแก้ปัญหา |
| H5 | Result-first | โชว์ผลลัพธ์ก่อน แล้วค่อยย้อนเล่า | ก่อน/หลัง, DIY |
| H6 | Social proof | "2 ล้านคนซื้อเดือนที่แล้ว" | สินค้าที่มียอดจริง |
| H7 | Pattern interrupt | ภาพ/เสียงที่ไม่คาดคิด, ตัดเข้าฉากกลางการกระทำ | ทุกหมวด |
| H8 | POV / story | "POV: คุณเพิ่งเจอวิธีที่เปลี่ยนทุกอย่าง" | lifestyle, relatable |

### 3.3 กติกาเขียน hook (ใช้กับ AI ได้)
1. **เขียน hook line ก่อน concept** — concept ที่ไม่มี hook line ยังไม่พร้อมผลิต
2. **ห้ามขึ้นด้วยโลโก้ / product shot on white / สโลแกน**
3. **hook ต้องบอก "ใคร" หรือ "อะไร" ภายใน 1 วินาที** — vague = ตาย
4. **hook 1 บรรทัด ≤ 7 คำ** สำหรับข้อความบนจอ
5. **ทดสอบ 3–5 hook ต่อ 1 body** — เปลี่ยนแค่ 3 วินาทีแรก ที่เหลือเหมือนเดิมเป๊ะ

### 3.4 Hook testing protocol
```
1 body (proven) × 4 hooks  →  เปิดพร้อมกันใน ad group เดียว (หรือ 4 ads)
วัด: 3s view rate (hook rate), completion, CTR, CPA
ตัดสิน: 3-5 วัน หรือ ≥1,000 impressions/ตัว
ผู้ชนะ: body เดิม + hook ใหม่ → ป้อนกลับเข้า pipeline
```

**KPI ของ hook:** `hook rate = 3-second video views ÷ impressions`
- ต่ำกว่า 20% → hook อ่อน (เปลี่ยน hook)
- 20–30% → พอใช้
- >30% → แข็ง (เอา body ไปต่อยอด)

## 4. Native feel — กฎที่ทำให้ creative ไม่ถูกมองว่าเป็นแอด

| ✅ ทำ | ❌ ไม่ทำ |
|---|---|
| ถ่ายมือถือ, แสงธรรมชาติ/ring light | สตูดิโอ, ไฟ 3 จุด, ฉากหลัง greenscreen |
| คนจริงพูดกับกล้อง | ตัวอักษรลอยเดี่ยว ๆ บนพื้นหลัง gradient |
| ตัดทุก 2–3 วินาที | ช็อตนิ่ง 8 วินาที |
| ใช้เสียง/เพลงจาก Commercial Music Library | เพลงจาก trending ที่ไม่ clearing สำหรับโฆษณา |
| Caption แบบ burn-in | พึ่ง auto-caption ของ platform |
| มี background noise บ้าง | เสียงห้องอับ/เสียงบูด |
| ถ่ายกลางการกระทำ (mid-action) | เริ่มด้วย fade-in จากดำ |

## 5. Creative matrix — วิธีไม่ตันไอเดีย

ผลิตเป็น **matrix** ไม่ใช่เป็นชิ้น:

```
แกน A · Concept (angle)      : problem / result / social proof / demo / comparison / routine
แกน B · Hook (H1-H8)         : 1-3 วินาทีแรก
แกน C · Format               : talking head / UGC unboxing / POV / screen-record / ASMR / GRWM
แกน D · Length               : 9-15s / 21-34s / 45-60s
แกน E · Creator              : แบรนด์ / ครีเอเตอร์ A / ครีเอเตอร์ B / พนักงาน
```

**อย่าผลิตเต็ม matrix.** เลือก 1 concept × 1 format × 3 hooks ก่อน → เมื่อมี winner แล้วค่อยขยายแกนที่ชนะ (นี่คือ "scale by variation")

**ลำดับการทดสอบ (ทำจากล่างขึ้นบน):**
```
สัปดาห์ 1: CONCEPT  — หา angle ที่ชนะ (3-5 concept)
สัปดาห์ 2: FORMAT   — format ไหนเล่า angle นี้ได้ดีสุด
สัปดาห์ 3: HOOK     — 3-5 hook บน body ที่ชนะ
สัปดาห์ 4: POLISH   — CTA, end card, ความยาว, pacing
```
> การ optimize hook ก่อนเจอ concept ที่ชนะ = เสียเวลา

## 6. Spark Ads — creative ที่ถูกที่สุดและได้ผลดีที่สุด

**Spark Ads** = โพสต์ออร์แกนิกจริง (ของแบรนด์หรือครีเอเตอร์) ที่เอาสิทธิ์มา boost. ไม่ต้องผลิตใหม่, มี social proof ติดมา (ไลก์/คอมเมนต์/แชร์จริง)

| ข้อ | รายละเอียด |
|---|---|
| สิทธิ์ | ต้องขอ authorization code จากเจ้าของโพสต์ (ครีเอเตอร์) — อายุ ~30 วัน |
| ตัวเลข | completion rate สูงกว่า in-feed ถึง +134%, CVR +69% [vendor, TH] ; engagement lift 2.4× [vendor] |
| ราคา | CPC ถูกกว่า in-feed ปกติ |
| ใช้เมื่อไหร่ | มีโพสต์ที่ organic ดีอยู่แล้ว, มี affiliate content, ต้องการ social proof |
| ข้อควรระวัง | โพสต์ที่ boost ต้องยัง compliant (ถ้าครีเอเตอร์พูด claim เกิน แอดก็ติดไปด้วย) |

**ลำดับความสำคัญของ creative source:**
```
1. Affiliate/creator content ที่มียอดขายแล้ว   ← ดีสุด (พิสูจน์แล้ว + social proof)
2. Spark Ads จากโพสต์ออร์แกนิกที่ engagement ดี
3. UGC ที่จ้างผลิต (brief แน่น)
4. Brand-produced native-style
5. AI-generated (Symphony) — สำหรับ variation/ไอเดีย ไม่ใช่ hero
```

## 8. AI creative workflow (ประหยัดเวลาโดยไม่ลดคุณภาพ)

```
[1] RESEARCH   Creative Center → Top Ads (กรอง industry+region+objective)
               + Keyword Insights (คำที่แอดที่ work ใช้) + Trends
                          ↓
[2] IDEATE     Symphony Assistant / LLM: ขอ 20 hook จาก 5 angle
               → คัดเหลือ 6 ที่ "พูดเหมือนคนจริง" (มนุษย์ตัดสิน)
                          ↓
[3] SCRIPT     เขียน 3 script × 3 hook (body เดียว)
                          ↓
[4] PRODUCE    ถ่ายจริง (มือถือ) สำหรับ hero
               Symphony Creative Studio / Pippit / Creatify สำหรับ variation
                          ↓
[5] REVIEW     ตรวจ: hook ≤3s · 9:16 · safe zone · caption · compliance
                          ↓
[6] TEST       ABO creative test → อ่าน hook rate + CPA
                          ↓
[7] SCALE      winner → Smart+/GMV Max · +variation ของ hook ที่ชนะ
                          ↓
[8] LEARN      ป้อนผลกลับเข้า [1]: pattern ที่ชนะคือ input ของรอบถัดไป
```

**ข้อควรระวังกับ AI creative:**
- 2026 TikTok **แบน AI endorsement** ที่จำลองบุคคล/เสียงคนดัง และติดป้าย AI content — ต้อง disclose
- AI เก่ง variation แต่ **ไม่เก่ง creative direction** — ถ้าให้ AI คิด angle ทั้งหมดจะได้ของกลาง ๆ
- AI avatar ใช้ได้กับ volume/iteration แต่ retention มักต่ำกว่าคนจริงในหมวดที่ต้องมีความเชื่อใจ (health, finance)

## 9. Creative refresh — ตัดสินจากสัญญาณ ไม่ใช่อารมณ์

| สัญญาณ | แปลว่า | ทำอะไร |
|---|---|---|
| Hook rate ลด >20% จาก baseline | hook fatigue | เปลี่ยน 3 วินาทีแรก (body เดิม) |
| Frequency >2.5–3 /7 วัน | audience saturation | เพิ่ม creative ใหม่ หรือขยาย reach |
| CPA เพิ่ม >25% ต่อเนื่อง 3 วัน | creative หรือ offer อ่อน | เพิ่ม 3-5 creative ใหม่ก่อนแตะ bid |
| CTR ดี แต่ CVR ตก | ปัญหาอยู่ที่ landing/product page | อย่าโทษ creative — แก้หน้าเว็บ |
| Completion ตกแต่ hook ดี | body ยาว/ pacing ช้า | ตัดให้สั้นลง, เพิ่มการตัดฉาก |

**ปฏิทิน refresh ขั้นต่ำ:** 2–3 ชิ้น/สัปดาห์ · ทบทวน creative-level report ทุก 7 วัน · kill ตัวที่ต่ำกว่า ROAS floor **ที่ระดับ creative ไม่ใช่ระดับ campaign**

## 10. Checklist ก่อนส่ง creative เข้าแคมเปญ

- [ ] 9:16, 1080×1920, ≥720p
- [ ] hook เกิดภายใน 1–3 วินาที, ไม่มีโลโก้/สโลแกนก่อน
- [ ] ข้อความสำคัญอยู่ใน safe zone (กลาง 80%)
- [ ] caption ≤100 ตัวอักษร, มี keyword ที่คนค้น
- [ ] มีเสียง (voiceover หรือ music) + burn-in caption
- [ ] ตัดฉากทุก 2–3 วินาที
- [ ] CTA ปรากฏใน 2–3 วินาทีสุดท้าย (ทั้งภาพและเสียง)
- [ ] ปลายทางตรงกับ CTA (ไม่ใช่เด้งไปหน้าแรก)
- [ ] ผ่าน compliance (claims, disclosure, music license)
- [ ] มี hook อย่างน้อย 2 แบบต่อ concept
- [ ] ตั้งชื่อตาม convention (ConceptID_HookID_Format_Length_vN)
